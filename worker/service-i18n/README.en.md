# Inference service package

Generated by Wulabel. It pulls camera video streams, runs your trained model on them and pushes an alert when a target is found. It also provides an HTTP detection API.

## Run

Requires Python 3.9 or later (no PyTorch or GPU needed).

- Windows: double-click `run.bat`
- Linux: `sh run.sh`

The first run creates a Python environment and installs onnxruntime, opencv and numpy (about 100 MB). After that it starts right away.

To run inference on an NVIDIA GPU: replace `onnxruntime` with `onnxruntime-gpu` in `requirements.txt`, delete the `venv` folder and run again.

## Configuration: config.json

```jsonc
{
  "model": "model.onnx",
  "gpu": true,                 // use the GPU when onnxruntime-gpu is installed
  "max_side": 1280,            // shrink the long side of each frame to this size before detection; smaller is faster
  "port": 8090,                // HTTP API port
  "interval": 1.0,             // detect one frame every N seconds per stream
  "streams": [
    {
      "name": "North gate",
      "url": "rtsp://admin:password@192.168.1.64:554/Streaming/Channels/101",
      "region": [[0.1, 0.4], [0.9, 0.4], [0.9, 1.0], [0.1, 1.0]]  // optional: detection region, coordinates as 0–1 ratios
    }
  ],
  "alert": {
    "labels": ["no_helmet"],   // only alert on these classes; empty means all classes
    "min_score": 0.5,          // confidence threshold
    "class_scores": {},        // per-class thresholds, e.g. {"scratch": 0.3}; other classes use min_score
    "cooldown": 60,            // alert at most once per N seconds for the same stream and class
    "hours": "07:00-19:00",    // active hours; empty means all day; across midnight write "22:00-06:00"
    "save_image": true         // save alert snapshots to alerts/
  },
  "webhook": { "url": "http://your-platform/api/alarm", "with_image": false, "headers": {} },
  "mqtt": { "host": "", "port": 1883, "topic": "xlabel/alarm", "username": "", "password": "" },
  "reflux": { "enabled": true, "low": 0.3, "high": 0.5, "interval": 60 }
}
```

- Streams can be RTSP, HTTP-FLV, HLS (m3u8) or MP4 over http. A stream can also be a local video file path, for testing (local files and http on-demand videos loop by default).
- The detection region is checked against the **bottom-center point** of each box (where a person or vehicle stands).

## Alert message

Messages sent to the Webhook (POST JSON) and MQTT:

```json
{
  "stream": "North gate",
  "time": "2026-11-01T08:30:15",
  "labels": ["no_helmet"],
  "detections": [{ "label": "no_helmet", "score": 0.91, "box": [x, y, w, h] }],
  "width": 1920,
  "height": 1080,
  "image": "alerts/20261101/North gate_083015.jpg"
}
```

With `with_image` enabled on the Webhook, an extra `image_base64` field (JPEG with boxes drawn) is included.

## Results by model type

The fields of each item in `detections` depend on the model. The `task` returned by `GET /health` and `POST /predict` tells you which kind it is:

| Model | task | Fields of each item |
|---|---|---|
| Object detection | `detect` | `label`, `score`, `box` [x, y, w, h] |
| Instance segmentation | `segment` | Same, plus `polygon` [x1, y1, x2, y2, …] (object outline, original image pixels) |
| Keypoints | `pose` | Same, plus `keypoints` [x, y, v, …] (v = 2: found, 0: not found); alert snapshots draw the skeleton from `skeleton` in `config.json` |
| Image classification | `classify` | `label`, `score`, no `box`: one item per class whose probability reaches `min_score` (up to 5; no limit for multi-label models). Classification looks at the whole frame and ignores `region` |

## HTTP API

| Endpoint | Description |
|---|---|
| `GET /health` | Service status and whether each stream is online |
| `GET /alerts?limit=50` | Recent alerts |
| `GET /alerts/20261101/xxx.jpg` | Alert snapshot |
| `POST /predict?conf=0.4` | Upload an image (raw image file as the request body, or JSON `{"image": "base64"}`) and get detections back |

```bash
curl -X POST --data-binary @test.jpg "http://127.0.0.1:8090/predict?conf=0.4"
```

## Field data loop

Frames the model is unsure about (confidence between `low` and `high`) are saved to `reflux/` (at most one per stream every `interval` seconds).
Copy the `reflux` folder back from time to time, click "Import field images" on the Deploy page in Wulabel, annotate them and retrain — the model gets better the longer you use it.
