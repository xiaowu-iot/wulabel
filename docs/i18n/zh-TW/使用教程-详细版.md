## 1. 安裝與第一次啟動

### 1.1 下載安裝

1. 開啟官網 <https://wulabel.xiaowuiot.com>，點右上角的**下載**，或到 GitHub 的 Release 頁面下載。
2. Windows：下載 `Wulabel_版本號_x64-setup.exe`，按兩下後依提示安裝，裝好後從開始功能表或桌面開啟 **Wulabel**。
3. Mac：下載 `Wulabel_版本號_universal.dmg`，按兩下開啟，把 Wulabel 拖進「應用程式」資料夾。
4. Linux（v0.4.0 起）：下載 `Wulabel_版本號_amd64.deb`，在終端機執行 `sudo apt install ./Wulabel_版本號_amd64.deb`，裝好後在應用程式選單中開啟 **Wulabel**；也可以下載 `.AppImage`，執行 `chmod +x Wulabel_版本號_amd64.AppImage` 後按兩下執行，不用安裝。 ARM 電腦（飛騰、鯤鵬）請下載 `Wulabel_版本號_arm64.deb` 或 `Wulabel_版本號_aarch64.AppImage`（v0.4.2 起），用法相同。

- 系統需求：Windows 10 / 11（64 位元）；macOS 11 以上（Apple 晶片和 Intel 都能用）；Linux x86_64（Ubuntu 22.04 以上、Debian 12、統信 UOS、x86 電腦上的銀河麒麟等）；Linux ARM64（v0.4.2 起，飛騰、鯤鵬電腦上的銀河麒麟、統信 UOS 等，請下載檔名含 `arm64` 或 `aarch64` 的版本）。
- 暫不支援：龍芯、鴻蒙。鴻蒙裝置可以用瀏覽器參與團隊協作標註。
- Windows 第一次開啟時如果提示缺少 WebView2，依提示安裝即可（大多數 Win10 / 11 已經內建）。
- Mac 第一次開啟會提示「無法驗證開發者」（軟體沒有 Apple 開發者簽章）：在「應用程式」中**按右鍵** Wulabel → 打開 → 再點「打開」；macOS 15 以後請先按兩下一次，再到「系統設定 → 隱私權與安全性」最下方點「強制打開」。如果提示「已損毀」，在終端機執行 `xattr -cr /Applications/Wulabel.app` 再開啟。只有第一次需要這樣做。

### 1.2 認識主畫面

開啟後會先看到**專案**頁。開啟一個專案後，左側是導覽列，由上到下是：

| 頁面 | 做什麼 |
|---|---|
| 專案 | 建立、開啟、切換專案 |
| 資料 | 匯入圖片 / 影片 / 資料集，管理圖片，匯出資料集 |
| 標註 | 畫框、畫輪廓、選類別、點關鍵點，AI 輔助和預標註 |
| 健檢 | 找出漏標、標錯、重複圖片等問題 |
| 訓練 | 選模型、調參數、開始訓練，查看訓練紀錄 |
| 評估 | 查看指標、混淆矩陣、錯誤案例，建議閾值，誤報測試，匯出報告 |
| 部署 | 即時驗證、匯出模型、產生推論服務包、匯入現場回流 |
| 審核 | 團隊協作時才有：依成員、狀態篩選，批次通過或退回，抽檢 |
| 協作 | 即時多人協作：開啟共用（區域網路 / 線上）、成員、分配任務、進度統計 |
| 設定 | 安裝訓練環境、下載來源、巡瞳 AI |

右上角有**意見回饋**按鈕和**關閉專案**。

## 2. 設定：訓練環境、下載來源、巡瞳 AI

如果只做標註、匯入匯出，不訓練，這一章可以先略過。

### 2.1 一鍵安裝訓練環境

1. 點左側的**設定**。
2. 看「訓練環境」這一欄：
   - **顯示卡**這一行顯示偵測到的顯示卡、顯示記憶體、驅動程式和支援的 CUDA 版本。沒有 NVIDIA 顯示卡會提示「只能用 CPU 訓練（會慢很多）」。
   - **PyTorch 版本**下拉選單會自動選好推薦的版本（標有「推薦」字樣），一般不用改：
     - CUDA 12.8：RTX 50 系列等新顯示卡；
     - CUDA 13.0：需要較新的驅動程式；
     - CUDA 11.8：較舊的顯示卡和驅動程式；
     - CPU 版：沒有 NVIDIA 顯示卡。
3. （選用）**安裝位置**：預設裝在 C 槽的本機資料目錄。C 槽空間不夠時，點選擇換到空間大的磁碟，再點**儲存**。
4. 點**一鍵安裝**。GPU 版約 3GB，會自動下載 uv、Python 3.11、PyTorch，介面上會顯示「第幾/5 步」和下載進度、剩餘時間。只需要安裝一次。
   - 網路斷了會從中斷處接著下載，網路慢也不會中途失敗；想停下時點**取消**。
   - 選的 PyTorch 版本和顯示卡、驅動程式不相符時（例如沒有 NVIDIA 顯示卡卻選了 GPU 版、選的 CUDA 版本比驅動程式支援的新、RTX 50 系列選了舊版本），開始前會先提醒。
   - 驅動程式太舊、只能安裝 CPU 版時，會寫明把驅動程式更新到哪個版本以上就能用顯示卡訓練。
5. 裝好後狀態會變成**就緒**，下方顯示「顯示卡可用（cuda）」。
   - 缺少 numpy、onnx、opencv 等元件時會列出來，點**補裝缺少的元件**只安裝缺少的那幾個。
   - 裝的是 GPU 版但顯示卡無法使用時，會顯示黃色提示「顯示卡無法使用，目前用 CPU 訓練」。
6. 安裝失敗時，在失敗的對話框中可以直接點**回報這個問題**，安裝日誌會自動附上。

> 訓練環境是獨立的，不會影響系統中其他的 Python。

### 2.2 下載來源

1. 還沒選擇過時，中文介面預設使用中國大陸鏡像，其他語言預設使用官方來源。
2. 在「下載來源」這一欄點**測速並推薦**。軟體會從官方來源和中國大陸鏡像各下載幾 MB 測速，自動選擇較快的那一個。
3. 選擇「中國大陸鏡像」時，SAM、文字提示這些輔助模型也會從中國大陸鏡像（hf-mirror.com）下載。
4. uv（安裝 Python 用的工具）、ffmpeg（影片擷取影格用）一般會自動下載。無法自動下載時，可以自行安裝好後，在「uv 和 ffmpeg（進階）」中指定它們的位置。

### 2.3 巡瞳 AI（選用）

想用巡瞳 AI 平台的模型自動標註、上傳模型、拉取警報圖片，或用「巡瞳官方中繼」線上協作時才需要：

1. 在「巡瞳 AI」這一欄點**登入巡瞳 AI 帳號**。
2. 瀏覽器會開啟巡瞳 AI 的網頁：還沒登入就先登入（和平常登入巡瞳一樣），然後核對網頁上的確認碼和 Wulabel 中顯示的是否相同，點**允許**。
3. 回到 Wulabel，幾秒後會自動顯示**已登入**、帳號名稱、方案和剩餘額度，以及可用的辨識方式（依專案類別辨識、平台上開通的專用模型、大模型通用辨識）。不用複製貼上 Key。
4. 瀏覽器沒有自動開啟時，點**重新開啟**，或複製視窗中的位址自己開啟。
5. **登出**：這台電腦上的 Key 會被刪除，登入時自動建立的 Key 也會在平台上撤銷。

如果已經有 API Key，或巡瞳是私有化部署的，點**進階：手動填寫 API Key、私有化部署的平台位址**，填好後點**儲存並測試連線**。連線狀態會一直顯示在這一欄。

### 2.4 使用現有的 Python 環境（進階）

如果已經有裝好 PyTorch 的 Python 環境，可以不用再下載：

1. 展開「使用現有的 Python 環境（進階）」。
2. 點**選擇 python.exe**，選擇環境中的 `python.exe`（例如 `D:\envs\torch\Scripts\python.exe`）。
3. 點**儲存**。這個環境需要有 torch、torchvision、numpy、pillow；匯出 ONNX 還需要 onnx。
4. 想改回軟體自己的環境：清空路徑再儲存。

### 2.5 檢查更新

軟體啟動時會自動檢查一次有沒有新版本，有的話右下角會跳出提示。點**立即更新**，軟體會在背景下載新版本、驗證無誤後自動安裝，裝好後自行重新開啟，中間不用點任何按鈕（Windows 只會顯示一個安裝進度列；Linux 用 .deb 安裝的，v0.4.2 起也能自動更新，安裝時可能要輸入一次系統密碼），專案和資料都會保留（v0.4.1 起）。也可以點「前往下載」開啟下載頁。不想再看到某個版本的提示，點「這個版本不再提醒」。正在訓練、安裝訓練環境、即時驗證或協作共享時點更新，會先列出這些工作，可以選擇**先不更新**；下載更新時可以關閉對話框，下載會在背景繼續，下載完自動安裝。在設定頁最下方的「關於與更新」中也可以手動點**檢查更新**。

檢查更新時只會傳送軟體版本、系統類型和一個隨機的匿名編號，用來統計大概有多少人在使用，不含圖片、專案和任何個人資訊。不想連網檢查，在「關於與更新」中關閉**啟動時自動檢查更新**即可。

### 2.6 語言、外觀和巡瞳 AI 開關

設定頁最上面可以改這幾項：

- **語言 / Language**（v0.5.0 起）：介面支援 简体中文、繁體中文、English、日本語、한국어、Español、Português、Русский、Deutsch、Français、Tiếng Việt、Bahasa Indonesia。預設**跟隨系統**（中文系統顯示中文，沒有對應語言的顯示英文），改了之後介面會重新載入。訓練日誌、錯誤提示、交付報告和推論服務包的說明也用這個語言。
- **外觀**（v0.5.1 起）：**跟隨系統**、**淺色**、**深色**。預設跟隨系統的淺色或深色模式。標註畫布、圖片預覽等看圖的區域始終是深色，方便看清圖片。
- **巡瞳 AI 開關**（v0.5.2 起）：「巡瞳 AI」卡片右上角的開關。簡體中文介面預設開啟；其他語言預設關閉，關閉時標註頁的巡瞳 AI 和辨識規則、資料頁的拉取警報圖片、部署頁的上傳巡瞳、協作頁的巡瞳官方中繼都不會顯示，需要的話開啟即可。

## 3. 建立和開啟專案

**一個專案就是一個資料夾**：圖片（複製進來的）、標註、模型、訓練紀錄都在裡面，整個資料夾複製到另一台電腦也能直接開啟。

第一次使用時，「專案」頁上方有**新手導覽**，依照安裝訓練環境、建立專案、匯入圖片、標註一小批、訓練、預標註和部署六個步驟帶你走一遍，完成的步驟會自動打勾；點右上角的 × 可以關閉，之後點「顯示新手導覽」還能再開啟。

「最近的專案」卡片上會顯示專案封面、圖片數、已標註多少張（進度列）和訓練過幾次，一眼就能看出每個專案做到哪裡。

### 3.1 建立專案

1. 在**專案**頁點**建立專案**。
2. **專案名稱**：例如「工地安全帽偵測」。
3. **存放位置**：預設是「文件/Wulabel」，也可以點**瀏覽**換一個資料夾，專案會建立在這個資料夾下。
4. **任務類型**（建立後無法修改）：

   | 任務 | 標註方式 | 適合 |
   |---|---|---|
   | 物件偵測 | 矩形框 | 找出安全帽、車輛、煙火的位置 |
   | 實例分割 | 多邊形輪廓 | 需要精確形狀：積水範圍、垃圾堆、瑕疵區域 |
   | 影像分類 | 整張圖一個類別 | 畫面「正常 / 異常」、場景分類 |
   | 多標籤分類 | 整張圖可以有好幾個類別 | 一張圖同時有幾種情況：商品的多種損壞、場景裡的多個屬性 |
   | 關鍵點 | 目標框 + 依範本逐一點選 | 人體姿態（跌倒、攀爬）、物體關鍵部位 |

5. **類別**（可以不填）：先把要標的類別寫好，用逗號或換行分隔，例如「安全帽, 人, 反光衣」。不填的話，之後隨時可以在標註頁新增。
6. 點**建立**，會提示「專案『…』已建立」並自動開啟。

### 怎麼選任務類型

任務類型建立後無法修改，先依照下面三個問題想清楚：

1. **需不需要知道東西在畫面的哪裡？** 要知道位置、要數有幾個，選物件偵測、實例分割或關鍵點；只在意「這張圖是什麼、有什麼問題」，選影像分類或多標籤分類。
2. **位置要多精確？** 大概的位置（一個框）就夠，選**物件偵測**；要精確的形狀、面積、邊界，選**實例分割**；要知道人或物體各個部位在哪裡（頭、手、腳），選**關鍵點**。
3. **一張圖有幾個結論？** 只有一個，而且互相排斥（良品或不良品、白天或夜間），選**影像分類**；可能同時成立好幾個（既有刮痕又缺配件），選**多標籤分類**。

常見情境怎麼選：

| 情境 | 建議類型 | 怎麼標 |
|---|---|---|
| 工地安全帽、反光衣、人員計數 | 物件偵測 | 每個人頭、每件反光衣各畫一個框 |
| 煙火、明火、車輛、行人 | 物件偵測 | 框住每個目標；煙火形狀不規則，框住大致範圍就好 |
| 積水、漏油、垃圾堆的範圍和面積 | 實例分割 | 描出輪廓 |
| 產品表面的裂紋、刮痕、缺損位置 | 實例分割（要形狀）或物件偵測（只要位置） | 細長、不規則的瑕疵用輪廓，否則畫框 |
| 跌倒、攀爬、舉手等姿態 | 關鍵點 | 先畫人的框，再依範本點 17 個點 |
| 產線良品 / 不良品、儀表正常 / 異常 | 影像分類 | 每張圖按數字鍵選一個類別 |
| 場景分類：白天 / 夜間、室內 / 室外 | 影像分類 | 同上 |
| 電商退貨判斷損壞類型（扇葉損壞、灰塵髒污、配件缺少……） | 多標籤分類 | 每張圖勾選所有看到的損壞，沒問題的勾「全新」 |
| 商品照片標屬性（顏色、款式、有沒有包裝） | 多標籤分類 | 每張圖勾選所有符合的屬性 |

容易選錯的幾種情況：

- **分類還是偵測**：一張圖裡有好幾個目標、目標很小，或者要回報位置、數量，用偵測。整張圖只有一個主體、只在意它是什麼，用分類，標起來快得多（一鍵一張）。
- **單標籤還是多標籤**：類別之間互相排斥、每張圖只能是其中一個，用影像分類；可以同時有好幾個，用多標籤分類。多標籤專案裡每張圖至少要有一個類別，所以要加一個「全新」「正常」這類的類別給沒問題的圖。
- **偵測還是分割**：只要警報、計數、看位置，用偵測；要算面積或精確邊界才用分割。分割標起來比畫框慢很多。
- **問題很小**：瑕疵只佔畫面很小一塊時，整張圖分類可能看不出來。可以改用偵測把瑕疵框出來，或者拍近一點，讓瑕疵在畫面中大一些。
- **訓練用的圖**：拼接起來的對比圖、畫了紅圈或文字標記的圖，別直接拿去訓練，模型可能會學成「有紅圈就是有問題」。盡量使用原圖。

拿不準的話，先建一個小專案標幾十張圖，試著訓練一次，看評估結果再決定。

### 3.2 開啟專案

- 在**最近的專案**清單中點一下就能開啟；清單會顯示每個專案上次開啟的時間。
- 不在清單中的，點**開啟專案…**，選擇專案資料夾。
- 專案資料夾被移走後，清單中會提示「找不到資料夾」：點**重新定位…**選擇它的新位置就能繼續使用；資料夾已經刪除的，點「從清單移除」（不會刪除檔案）。

## 4. 匯入資料

點左側的**資料**。

### 4.1 匯入圖片或資料夾

1. 先在頁面頂端選擇匯入方式：
   - **複製到專案**：圖片會複製進專案資料夾，專案可以整個帶走（推薦）；
   - **只參照原路徑**：只記錄圖片原本的位置，不占額外空間，但原圖不能移動。
2. 匯入：
   - 點**匯入資料夾**，選一個資料夾（會自動尋找子資料夾中的圖片）；
   - 或點**更多匯入方式 → 匯入圖片檔案**，選幾張圖片；
   - 或直接把圖片、資料夾**拖進視窗**，看到「放開滑鼠匯入圖片或影片」時放開。拖進來的是影片檔案的話，會直接開啟「影片擷取影格」對話框（見 4.2）。
3. 匯入時會分兩段顯示進度：先是「已處理 N / M 張（計算指紋、產生縮圖）」，再來是「複製並寫入 N / M 張」（只參照原路徑時是「寫入專案」）。一次匯入幾萬張圖也不會卡住，匯入過程中縮圖照常可以查看。選錯了可以點**停止**，已經處理的圖照常存入。完成後會提示新增幾張、略過幾張重複的，點提示中的**開始標註**直接前往標註頁。

匯入時會自動**依內容去除重複**（同一張圖不會匯入兩次），並依照片的 EXIF 資訊**轉正方向**。

### 4.2 匯入影片（擷取影格）

1. 點**更多匯入方式 → 匯入影片（擷取影格）**，選擇一部或多部影片檔案。
2. 在「影片擷取影格」對話框中設定：
   - **每隔 N 秒擷取 1 個影格**：目標變化慢就隔久一點，避免一堆幾乎一樣的圖；
   - **每部影片最多 N 個影格**（0 = 不限）。
3. 點**開始擷取影格**。第一次使用會自動下載 ffmpeg（約 90MB），之後不用再下載。參數設錯了可以點**停止**，已經擷取出的影格照常匯入。
4. 擷取出的影格會複製進專案，並依內容自動去除重複。完成後會提示「從 N 部影片擷取 M 個影格：新增 K 張」。

### 4.3 從影像串流擷取影格（RTSP / 直播 / 回放）

1. 點**更多匯入方式 → 從影像串流擷取影格（RTSP / 直播 / 回放）**。
2. 填寫位址：RTSP 攝影機（`rtsp://…`），或 http(s) 的直播、回放、隨選播放位址（mp4、m3u8、flv）。
   - 海康：`rtsp://使用者名稱:密碼@IP:554/Streaming/Channels/101`（主碼流）或 `102`（子碼流）
   - 大華：`rtsp://使用者名稱:密碼@IP:554/cam/realmonitor?channel=1&subtype=0`
3. 點**測試連線**，會顯示解析度，以及是「直播串流（無限，需設定上限）」還是「回放串流 · 時長 …」。
4. 設定：
   - **每隔 N 秒擷取 1 個影格**；
   - **最多擷取 N 個影格**、**最長採集 N 分鐘**（0 = 不限，僅直播）。**直播是無限串流，至少要設定其中一個**；
   - 勾選**略過幾乎相同的影格**：畫面靜止時少存重複的圖。
5. 點**開始採集**。圖片會邊採集邊存入，在資料頁就能看到一張張出現。
6. 採集中可以點**最小化**繼續做別的事，右下角會顯示「採集中 · 已擷取 N 個影格」，點**展開**回來；點**停止採集**可以隨時結束，已採集的圖會保留。
7. 採集的圖存在專案的 `images/stream_位址_時間/` 資料夾中，完成後可以點**開啟資料夾**查看。

> 帳號密碼只在採集時使用，軟體不會把含密碼的位址寫進專案資料夾的名稱。

### 4.4 匯入含標註的資料集

已經有在其他地方標好的資料，可以連同標註一起匯入：

1. 點**更多匯入方式**，依專案類型選擇：
   - 偵測 / 分割專案：**匯入含標註的資料集（YOLO / COCO / VOC）**，支援 YOLO（含 seg）、COCO（含分割）、VOC；
   - 關鍵點專案：**匯入含標註的資料集（YOLO-pose / COCO 關鍵點）**；
   - 分類專案：**匯入分類資料集（每個類別一個資料夾）**，所選資料夾下的每個子資料夾就是一個類別（也可以再多分一層 train / val）。
2. 選擇資料集的根資料夾，軟體會自動辨識格式。
3. 完成後會提示「已匯入 YOLO 資料集」等，以及新增了哪些類別。

### 4.5 批次操作、撤銷、刪除、清空

資料頁上方的統計卡片（未標註、已標註、已略過）可以點，點一下只看這一類圖，再點一下回到全部；下方的篩選按鈕也一樣。

都在**管理**選單中：

- **批次選取**：進入選取模式，點圖片勾選；按住 **Shift** 點另一張，可以連續選取一段；「全選本頁」選取這一頁，「選取全部 N 張」選取目前篩選條件下的所有圖。選好後可以：
  - **設為略過**：這些圖不參與訓練；
  - **恢復為未標註**：已經有標註的圖會恢復成已標註；
  - **前往標註**：只把選取的這些圖送到標註頁逐張標註；
  - **劃分**：移到訓練集、驗證集或測試集（只對已標註的圖有效，見 10.1）；
  - **刪除**。
  切換篩選或換頁時會清空已選取的圖，以免誤刪看不到的圖。最後點**完成**離開。
- **撤銷上次匯入（N 張）**：剛剛匯入錯了，一鍵刪除上次匯入的圖（影像串流的一次採集算一次匯入）。
- **清空全部圖片**：刪除專案中所有圖片。

刪除時圖片的標註會一併刪除，無法還原；複製進專案的圖片副本會被刪除，你電腦上的原圖不受影響。刪除的數量多時，對話框中會顯示刪除進度。

### 4.6 圖片品質篩查

模糊、太暗、過曝的圖標註起來費力，訓練時也容易把模型帶偏，可以先篩掉：

1. 點**管理 → 圖片品質篩查（模糊、過暗、過曝）**。
2. 預設勾選**只看未標註的圖**；想檢查全部就取消勾選。
3. 點**開始篩查**。
4. 結果依問題分類：**模糊**、**過暗**、**過曝**、**對比度低**，點上方的標籤篩選。每張圖下方有清晰度、亮度、過曝比例、對比度的數值。
5. 處理：
   - **逐張檢視**：跳到標註頁一張張看，自己決定；
   - **設為略過**：標成「略過」，不參與訓練（圖還在，之後可以撤回）；
   - **刪除**：直接刪除。

### 4.7 從巡瞳 AI 拉取警報圖片

模型部署到巡瞳 AI 平台後，現場的警報截圖（尤其是誤報、漏報）正是最值得補充的資料：

1. 先在**設定**中設定好巡瞳 AI（見 2.3）。
2. 在**資料**頁點**更多匯入方式 → 從巡瞳 AI 拉取警報圖片**。
3. 選擇時間範圍（最近 1 / 3 / 7 天；平台的警報圖片保留 7 天，記得定期拉取）、模型（全部或某一個）、**最多 N 張**。只有設定了推播管道的巡瞳帳號才會產生警報紀錄。
4. 預設勾選**將平台辨識出的框作為預標註**：依類別名稱對應專案中的類別，沒有的會新建。
5. 點**開始拉取**。圖片存在專案的 `images/xuntong_時間/` 資料夾，辨識框會以虛線顯示（來源「巡瞳」）。
6. 到標註頁檢查：誤報的框刪掉（沒有目標的圖直接按 **Enter** 完成，作為負樣本），漏掉的補上，然後重新訓練。

## 5. 標註

點左側的**標註**。

### 5.1 認識標註頁

- **頂端**：左右箭頭換圖、目前的圖名和序號（第幾張 / 共幾張，點序號可以輸入數字直接跳過去）、解析度、狀態標籤（未標註 / 已標註 / 已略過，沒有目標的圖顯示「沒有目標」）；篩選按鈕**全部 / 未標註 / 已標註 / 已略過**（團隊協作時變成**全部 / 未標註 / 待審核 / 已通過 / 已略過 / 被退回**，狀態標籤也一樣叫「待審核」「已通過」，見 9.4）；最右邊是縮放比例和儲存狀態（已儲存 / 未儲存 / 儲存中… / 儲存失敗）。
- **左側工具列**：選取、畫框（或畫輪廓）、SAM 智慧選取、復原、取消復原、複製上一張、關鍵影格插值、向後追蹤、符合視窗大小。滑鼠停在上面會顯示說明和快速鍵。
- **中間**：圖片畫布。用滾輪縮放，按住空白鍵或右鍵拖曳畫面。
- **右側**：「AI 輔助」、「類別」、「本圖物件」（分類專案是「本圖類別」）、「完成」幾個區塊（團隊協作時這個區塊叫「審核」）。
- **畫布下方**：目前專案可用的快速鍵提示；按 **?** 開啟所有快速鍵的說明面板。
- **最下方**：前後幾張圖的縮圖列，點一下直接跳過去。縮圖右上角的小圓點代表狀態：藍色是已標註、灰色是已略過，沒有圓點是未標註。

修改會**自動儲存**，不用手動儲存。

### 5.2 新增和管理類別

1. 在右側「類別」中的輸入框輸入「新類別名稱，按 Enter 新增」，例如「安全帽」，按 Enter。
2. 前 9 個類別可以用數字鍵 **1–9** 快速切換，目前類別會反白顯示。
3. 點類別旁邊的編輯按鈕可以：
   - 改名稱、改顏色；
   - 填寫**英文提示詞**（給「文字提示」自動標註用，可以寫多個，用逗號隔開，例如 `helmet, hard hat`）；
   - 填寫**辨識說明**（給巡瞳 AI「依專案類別辨識」用：這個類別具體指什麼、什麼情況算 / 不算，例如「頭上沒有安全帽的人；戴了帽子但沒繫帶也算」）；
   - 刪除類別。這個類別已經有標註時，可以在「合併到…」中選擇另一個類別，標註會改成那個類別，不會遺失（標錯類別、想把兩個類別合成一個時很好用）；不選擇就直接刪除，標註會一併刪除。

### 5.3 物件偵測：畫框

1. 按 **1–9** 選類別。
2. 按 **R**（或點左側的畫框工具），在目標上**按住滑鼠拖曳出一個框**。
3. 調整：按 **V** 切換到選取工具，點選框後可以拖曳位置、拉邊角調整大小。
4. 刪除：選取框後按 **Del** 或 **退格鍵**；按 **Esc** 取消選取。
5. 改類別：選取框後按數字鍵，或在右側「本圖物件」中修改。
6. 按 **H** 隱藏 / 顯示框上的類別名稱，框很密集時比較好看。

### 5.4 實例分割：畫輪廓

1. 選類別，按 **R**。
2. 沿著目標邊緣**一個點一個點地點擊**。
3. **按兩下**或按 **Enter** 閉合輪廓；點錯了按 **退格鍵** 刪除上一個點。
4. 選取輪廓後可以拖曳頂點微調。
5. 更快的方法是按 **S** 用 SAM 智慧選取，點一下自動產生輪廓（見第 6 章）。

### 5.5 影像分類：一鍵一張

1. 看圖，按數字鍵 **1–9** 選類別。畫面左上角會顯示目前的類別。
2. 開啟右側的**選完跳下一張**開關後，按完數字鍵會自動跳到下一張，一鍵一張。
3. 按 **Del** 清除這張圖的類別；按 **Ctrl+D** 沿用上一張的類別。

**多標籤分類**專案一張圖可以打好幾個類別：按 **1–9** 勾選、再按一次取消，勾完按 **Enter**；**Del** 清除全部，**Ctrl+D** 沿用上一張的全部類別，按 **P** 讓模型把分數達到信心度的類別都勾上。評估頁的主指標是 **mAP**，另有「標籤全對」的比例，錯例寫成「漏：… · 多：…」。

### 5.6 關鍵點

1. 先看右側的**關鍵點範本**。預設是「COCO 人體 17 點」（鼻子、左眼、右眼……左踝、右踝）。要修改就點**編輯**：
   - **範本名稱**；
   - **點名稱**（每行一個，點的順序就是標註時點擊的順序）；
   - **連線**（每行一對序號，如 `1-2`，用來畫骨架）；
   - 也可以點**使用 COCO 人體 17 點**恢復預設。
   - 已經有關鍵點標註後，只能修改名稱和連線，不能增減點數。
2. 選類別，按 **R** 畫出目標框。
3. 畫完框後依提示**依序點選每個關鍵點**（畫面下方會提示目前要點的是哪一個點，例如「點擊 左肩（6/17）」）：
   - 一般點擊：可見的點；
   - **Shift + 點擊**：被遮擋的點；
   - **N**：略過看不到的點；
   - **退格鍵**：回到上一個點；
   - **Esc**：結束這個目標。
4. 微調：選取目標後可以直接拖曳關鍵點。右側會列出每個點的狀態，點名稱可以單獨重新放置這個點；點狀態可以在「可見 / 被遮擋」之間切換。
5. 選取目標後點**重放關鍵點**，可以從第一個點開始重新標。

### 5.7 複製上一張、復原與取消復原

- **Ctrl+D**（或左側的複製按鈕）：把上一張的標註整組搬過來，場景相似或連續影格時很省事。分類專案則是沿用上一張的類別。
- **Ctrl+Z** 復原、**Ctrl+Y** 取消復原。

### 5.8 完成、略過

一個人標註時不用審核，標了目標的圖會自動算「已標註」，直接參與訓練。右側「完成」區塊：

- **完成並下一張**（快速鍵 **Enter**）：跳到後面第一張未標註的圖。
  - 這張圖確實沒有目標時，按 Enter 會把它記為「沒有目標」，作為**負樣本**參與訓練（教模型在這類畫面上不要誤報）。按錯了可以點提示中的**撤回**。
  - 批次預標註過的圖（虛線框）看過、修改好後按 Enter，就算已標註。
- **略過**（快速鍵 **X**）：標成「已略過」，這張不參與訓練。適合模糊、無關的圖。
- **撤回**：把「沒有目標」或「已略過」改回原來的狀態。
- **Shift+D**：直接跳到下一張未標註的圖。

標完最後一張時，會提示「這一批標完了」，顯示已標註和還沒標的張數，可以點**前往訓練**，或是**繼續標註未標註的**。

頂端篩選選擇「已略過」可以把略過的圖找出來複查。

團隊協作（加入了成員或開啟了即時協作）時才有審核流程，這個區塊會變成「審核」，按鈕是**通過並下一張**、**退回**；圖多時用左側的**審核**頁批次審核更快，見 9.4。

### 5.9 影片影格：關鍵影格插值、向後追蹤

適用於偵測和關鍵點專案。從影片擷取出的影格（在同一個資料夾中，依檔名排好順序）可以不用一個影格一個影格地畫。

**關鍵影格插值**（目標等速移動的片段）：

1. 翻到片段開頭的影格，把目標都標好（這就是一個「關鍵影格」）。
2. 翻到片段結尾的影格，也把同樣的目標標好。
3. 在結尾這個影格點左側的**關鍵影格插值**按鈕。
4. 軟體會依類別和位置把兩端的目標一一對應，自動補上中間的影格。會提示「已在中間 N 個影格上插值 M 個目標」；兩端對不上的目標會另外說明。

**向後追蹤**（目標移動不規則時）：

1. 在目前影格把目標標好。
2. 點左側的**向後追蹤**按鈕，在跳出的小視窗中填寫**影格數**（預設 30，最多 500），點**追蹤**。
3. 軟體會從這個影格的框出發逐格追蹤下去。目標被遮住或跟丟了就停止；遇到後面手動標過的影格也會停止，不會覆蓋人工標註。
4. 追蹤完會自動跳到最後追蹤到的影格。框偏了就拖正（拖過的框會變成手動標註，這個影格就成為新的關鍵影格），再點**向後追蹤**繼續追蹤。

插值和追蹤產生的框，在右側「本圖物件」中來源會顯示為「插值」「追蹤」。重新插值或追蹤會取代它們，手動標的框不會被改動。

> 省力的做法：先手動標一小批（幾十到一兩百張），訓練一個初版模型，再用它預標註剩下的圖（第 12 章），你只要修正錯誤。

## 6. AI 輔助標註

還沒有自己的模型時，也可以讓 AI 幫你標。

### 6.1 SAM 智慧選取

1. 選類別，按 **S**（或點左側的 SAM 按鈕）。
2. 第一次使用需要安裝元件、下載模型，可能要幾分鐘，畫面上會顯示「SAM 準備中…」，右下角會顯示「正在下載、安裝」和每個檔案的進度（中斷了會接著下載，只需一次）。有 NVIDIA 顯示卡時使用 SAM ViT-B，否則使用輕巧的 SlimSAM。
3. 在目標上**點一下**，會自動選出目標的輪廓（預覽）。
   - 選太多：**Shift + 點擊**多出來的地方來排除；
   - 選太少：再點沒選到的部分；
   - 點錯了按 **退格鍵** 刪除最後一個點；
   - 也可以**拖曳一個框**把目標框住。
4. 滿意後按 **Enter** 採用為目前類別；按 **Esc** 放棄。
5. 結果：分割專案會得到多邊形，偵測專案會得到貼齊邊緣的框，關鍵點專案會得到一個新目標（再點「重放關鍵點」標點）。

### 6.2 文字提示

依類別名稱自動在圖中尋找目標：

1. 在右側「AI 輔助」中選擇**文字提示**。
2. 模型只懂英文。常見的中文類別名稱（以簡體中文為準，如 安全帽、人员、电动车、渣土车、锥桶等一百多個）會自動對應英文，並顯示在類別名稱後面，例如「安全帽 · helmet」；類別名稱中包含這些詞也可以，例如「紅色安全帽」。繁體寫法和簡體不同的名稱（例如「人員」「電動車」）可能對不上；對不上或想修改的，請在類別的編輯中填寫**英文提示詞**。
3. 調整**信心值**：找到太多就調高，找不到就調低。
4. 點**標註本圖 (P)** 標註目前這張，或點**批次預標註**一次標一批。
5. 第一次使用需要下載模型，要幾分鐘。分割專案會再用 SAM 產生輪廓。

### 6.3 巡瞳 AI

（巡瞳 AI 的完整用法見第 16 章。）

1. 先在**設定**中設定好巡瞳 AI（見 2.3）。
2. 在「AI 輔助」中選擇**巡瞳 AI**，在「選擇辨識模型」中選擇：
   - **依專案類別辨識（推薦）**：只找專案中的類別，類別名稱原樣對應，依照每個類別的辨識說明和整體規則辨識，不會多認出你不需要的東西；
   - 平台上開通的**專用模型**；
   - **大模型通用辨識**：依安全隱患類別（消防、電氣、環境衛生等）尋找。
3. 點**標註本圖 (P)** 或**批次預標註**。用專用模型（例如垃圾分類）批次預標註很快：每次 8 張一批、兩批同時傳送；大模型和依專案類別辨識是一張一張處理，比較慢。
4. 巡瞳 AI 每張圖計 1 次呼叫，會消耗你帳號的方案額度；批次處理前會提示。

### 6.4 辨識規則：告訴 AI 怎麼辨識

只有類別名稱，AI 不一定知道你要的到底是什麼。可以把規則寫清楚，或直接和 AI 聊：

1. 在「AI 輔助」標題旁點**辨識規則**，右側會開啟辨識規則面板。
2. **和 AI 聊**：用白話說明要怎麼辨識，例如「戴了帽子但沒繫帶也算未戴安全帽」「反光衣不算」「只看畫面下半部的通道」，也可以問「這張圖左邊那個人為什麼沒認出來」。
   - 預設勾選**附上目前這張圖**，AI 會依新規則在這張圖上試辨識。
   - AI 回答後，如果它建議更新規則，會顯示「AI 建議更新規則」和具體內容，點**採用這些規則**才會儲存。
   - 試辨識有結果時，點**把試辨識的 N 個框加到這張圖**，直接作為預標註使用。
   - `Ctrl+Enter` 傳送。每次對話都會使用巡瞳 AI 的額度。
3. **目前規則**：可以直接修改**整體規則**（適用於所有類別）和**每個類別的辨識說明**，點**儲存規則**。
4. 之後用巡瞳 AI 的「依專案類別辨識」預標註時，就會依照這些規則。
5. （選用）在「目前規則」最下方點**同步到巡瞳平台**：把類別和規則存到巡瞳平台上。預設**不啟用**，不影響平台目前的辨識。綁定後，之後每次儲存或採用規則都會自動同步內容（不會改動你在巡瞳控制台中設定的啟用狀態和適用場景）。
6. 想讓巡瞳平台自己的辨識（抓拍助手、警報推播）也只回報你要的類別，就開啟**平台辨識也使用這套規則**。注意：開啟後整個巡瞳帳號的辨識都會依照這個專案的類別，適用場景可以在巡瞳控制台的「辨識規則」中調整。不想同步時點**解除綁定**（平台上的規則不會刪除）。每個巡瞳帳號最多 20 套辨識規則。

限制：依專案類別辨識最多 30 個類別，類別名稱不超過 30 個字；整體規則最多 1000 字，每個類別的辨識說明最多 500 字。

協作時，成員也能開啟辨識規則和 AI 聊（發起人開放 AI 輔助的話，使用的是發起人的額度）；能不能修改規則則依「成員可以新增、修改類別」開關而定。

### 6.5 檢查輔助結果

AI 標出來的框、輪廓會以**虛線**顯示。檢查一遍：錯的刪掉，偏的拖正，漏的補上，然後按 **Enter**（完成並下一張）。

## 7. 資料健檢

點左側的**健檢**，一鍵找出資料中的問題。

1. 選擇檢查方式：
   - 有訓練好的模型：選擇「用模型檢查：模型名稱 · mAP50 …」，規則和模型一起檢查；
   - 沒有模型：選擇「只做規則檢查（不用模型）」。
2. 點**開始健檢**。進度會分階段顯示：「重複檢查：計算指紋」→「重複檢查：兩兩比對」→「模型檢查」。圖多時要幾分鐘，可以點**停止**（停下的這次不會儲存結果）；離開健檢頁再回來，能看到還在執行的進度。檢查過的圖片指紋會快取，下次只計算新加入的圖。
3. 結果會依問題分類顯示：

   | 問題 | 意思 | 需要模型 |
   |---|---|---|
   | 疑似漏標 | 模型很確定這裡有目標，但沒有標註 | 是 |
   | 疑似類別錯誤 | 框的位置對上了，但類別和模型判斷的不一樣 | 是 |
   | 框不準 | 類別一致，但框和模型預測的重疊程度低 | 是 |
   | 疑似多餘框 | 標了框，但模型在這個位置什麼都沒看到 | 是 |
   | 極小框 | 短邊小於 8 像素，模型幾乎學不到 | 否 |
   | 重複框 | 同一張圖中同類別的兩個框幾乎完全重疊 | 否 |
   | 重複圖片 | 畫面幾乎一樣的圖片，會讓評估結果虛高 | 否 |
   | 無類別 | 框沒有類別，不會參與訓練 | 否 |

4. 每一筆問題可以：
   - **前往修改**：跳到標註頁，反白顯示這個框；
   - **加為標註**：疑似漏標時，直接依模型的判斷加一個框；
   - **不是問題**：忽略，以後健檢不再提示。
   某一類問題很多時，可以用**全部加為標註**（疑似漏標）或**全部忽略**一次處理完。忽略過的問題可以點「已忽略 N 條 · 還原」找回來。
5. 到標註頁修改過的圖，回到健檢頁時會標成「已修改」並預設收合，不用重新健檢。
6. 重複圖片會分組顯示，每張圖上標著狀態和標註數。綠框是要保留的那張，預設保留標註最完整的（審核通過的 > 已標註 > 標註較多的）；點其他圖可以更換，按兩下前往標註頁查看。點**每組只保留一張**刪除其餘的，有標註的圖不會被誤刪。
7. 頁面下方還有**類別分布**（框數 · 圖片數）和**框大小分布**，類別太少、框太小時會給出建議。分類專案只檢查疑似類別錯誤和重複圖片。

## 8. 資料集版本

把某個時間點的資料存成快照，方便比較和還原。

1. 在**資料**頁點**管理 → 資料集版本（儲存快照、比較、還原）**。
2. 填寫**版本名稱**（如 v1、補充夜間圖）和**備註**（選填），點**將目前資料儲存為新版本**。
   - 版本中儲存的是目前已標註的圖（團隊協作時是待審核和已通過的）和標註，以及訓練 / 驗證 / 測試的劃分。
3. 版本清單中的每一列可以：
   - **和目前資料比較**：查看新增的圖、移出的圖、標註有修改的圖，以及各類別標註數量的變化；
   - **匯出這個版本**；
   - **還原到這個版本**：還原前會自動把目前資料存成「還原前自動備份」版本，隨時能還原回來；
   - **改名、備註**、**刪除這個版本**（只刪除快照，不影響目前資料和已訓練的模型）。
4. 在**訓練**頁的「訓練資料」中可以選擇某個版本來訓練（見 10.1）。

## 9. 多人協作

圖很多、一個人標不完時，有兩種方式：

- **即時協作**：幾個人同時標同一個專案。你的電腦當主機，成員用瀏覽器開啟位址、登入後就能標，修改會即時同步。區域網路和外部網路都可以。
- **離線分包**：沒有網路，或資料不能離開公司時，把圖分成標註包複製給其他人，標完再合併回來（見 9.10）。

### 9.1 開啟即時協作

1. 點左側的**協作**。
2. 先在「成員」中新增成員：填寫**名字**（登入用），選擇**角色**，密碼預設隨機產生（可以修改），點**新增**。把跳出的帳號密碼複製下來傳給他（只顯示這一次，忘記了可以**重設密碼**）。
   - **標註員**：只能檢視、修改分給自己的圖；
   - **審核員**：能檢視全部的圖，負責審核通過或退回；
   - 你自己是**管理員**。
3. 在「共用」中選擇共用方式：
   - **區域網路**：成員和你在同一個公司網路、同一個 Wi-Fi，速度最快，資料不會離開公司。
   - **線上 · 自建中繼**：成員在外部網路（外包、在家工作）。需要一台你們自己的雲端伺服器安裝 Wulabel 中繼服務（儲存庫的 `relay/` 資料夾中有部署說明），填寫**中繼位址**和**金鑰**。資料只經過你們自己的伺服器。
   - **線上 · 巡瞳官方中繼**：成員在外部網路、又沒有自己的伺服器時使用。用你的巡瞳 API Key 連線到巡瞳的中繼伺服器。圖片和標註會經過巡瞳伺服器轉發（只轉發、不儲存），資料敏感的專案請用前兩種。
4. 填寫**你的名字**（成員看到的發起人名字）。**連接埠**一般不用改（預設 8765）。
5. 選項：
   - **成員可以使用 AI 輔助**：SAM 智慧選取、模型預標註、文字提示，都在你的電腦上運算；和 AI 聊辨識規則會使用你的巡瞳額度。
   - **成員可以新增、修改類別和辨識說明**：刪除類別會刪掉它的全部標註，只有你能做。
   - **成員的畫面疊加帶有他名字的浮水印**：防止截圖外流，適合外包。
6. 點**開啟協作**。頁面會顯示**區域網路位址**（如 `http://192.168.1.20:8765/`）；線上模式還會顯示**外部網路位址**（如 `https://relay.example.com/s/xxxxxxxxxxxx/`）。把位址和各自的帳號密碼傳給成員。
   - 第一次開啟時 Windows 可能跳出防火牆提示，請點**允許**。
   - 協作開啟期間，三個選項可以隨時修改，立即生效。
   - 點**停止協作**，成員會立即中斷連線，已經儲存的標註不受影響。切換專案、關閉 Wulabel 也會停止協作。

### 9.2 分配任務

1. 在「分配任務」中選擇標註員（可以點**選擇全部標註員**）。
2. 選擇範圍：
   - **還沒分配給人的未標註圖**（最常用）；
   - **全部未標註圖**（已分配的也重新分配）；
   - **還沒審核的圖**（未標註 + 待審核）。
3. **每人 N 張**：不填就把範圍內的圖平均分完。依圖片順序連續分配，影片的連續影格會分給同一個人。
4. 點**分配**。成員那邊會自動重新整理出新任務。
5. 在成員清單中能看到每個人分配了幾張、交了幾張、被退回幾張。點**收回任務**可以把他還沒交的圖收回，再分給其他人。

### 9.3 成員怎麼標（瀏覽器）

1. 用 Chrome 或 Edge 開啟發起人給的位址，填寫**名字**和**密碼**登入。自己的電腦可以勾選**記住登入**。不用安裝軟體。
2. 標註員進來就是標註頁，只會顯示分給自己的圖；審核員進來是審核頁（見 9.4），頂部可以切換到**標註**。操作和 Wulabel 中一樣：畫框、快速鍵、AI 輔助（發起人有開放的話）。右上角會顯示今天送出了幾張。
3. 標完點**送出並下一張**（`Enter`），等待審核。圖中確實沒有目標的，直接點送出，會作為負樣本進入待審核（分類專案要先選類別才能送出）。
4. 被退回的圖在篩選的**被退回**中，圖片上方會顯示退回原因，修改好再送出。
5. 別人正在標的圖會提示「某某正在標這張圖」，只能檢視，他的修改會即時顯示；他離開後會自動變成可以編輯。
6. 網路中斷時右上角會提示「即時連線中斷，正在重新連線」，恢復後會自動繼續，已經儲存的不會遺失。

### 9.4 審核

團隊協作時，圖片狀態分成：**未標註** → 標註員送出後是**待審核** → 審核員通過後是**已通過**；退回的圖在「被退回」中。資料頁、標註頁、健檢頁的篩選和狀態標籤都用這幾個名稱。一個人標註時沒有審核這一步，只顯示「已標註」。

審核有獨立的**審核**頁，只在團隊協作時出現（加入了成員或開著即時協作）：

- 你（管理員）：左側導覽多一個**審核**，旁邊的數字是待審核的張數。停止協作並刪除全部成員後，這一項會自動消失。
- 審核員（瀏覽器）：登入後預設就是審核頁，頂部可以在**審核 / 標註**之間切換。
- 標註員看不到審核頁。

**篩選**

1. **成員**：最上面一排是每個成員，顯示他的待審核張數和通過率（被通過 ÷ 被審核過的次數），通過率低於 80% 會標成黃色。點一個人只看他的圖，點**全部成員**看所有人的。
2. **狀態**：可以多選，預設只看**待審核**。也可以看已通過、被退回、未標註、已略過的圖。
3. **搜尋檔名**：輸入檔名的一部分。
4. **排序**：依送出時間（新的在前）或依檔名。
5. **更多篩選**：只看含某個類別的、只看沒有目標的（負樣本）、只看退回過的；還可以調整宮格中圖片的大小。**清除篩選**恢復預設。

**批次審核（宮格）**

1. 宮格中每張圖都畫出了框、輪廓或關鍵點（分類專案顯示類別名稱），圖片下方是檔名、標註人員、各類別個數和送出時間；退回過的圖會標示「退回過」。
2. 點圖勾選，按住 `Shift` 點另一張，會連同中間的一起選取。也可以點**全選本頁**，或**全選篩選結果**（包括後面幾頁，適合「把小明的待審核全部通過」）。
3. 點**通過**：選取的圖變成「已通過」。
4. 點**退回…**：勾選常見原因（漏標、框不準、類別標錯、多標了、關鍵點不對），或寫清楚哪裡要改，這幾張用同一個原因，各自回到原標註員的「被退回」中。
5. 有人正在修改的圖、不是待審核的圖會自動略過，提示中會寫明略過了幾張。
6. 點錯了：提示中的**復原**在 10 秒內有效，能把這批圖恢復成原本的狀態（之後又被別人修改過的圖不會動）。
7. 想看清楚某張：選取後按**空白鍵**放大檢視，左右鍵換圖，再按空白鍵關閉。

**逐張審核**

1. 按兩下一張圖，或點**逐張**，一張張看大圖，右邊是標註人員、送出時間、有沒有被退回過，以及每個類別標了幾個。
2. 沒問題點**通過**（`A`），會自動到下一張；有問題點**退回**（`R`）。
3. 想自己動手改：點**自己動手改**（`E`），會帶著這一批圖到標註頁，改完點標註頁上的**返回審核**回來，篩選和位置都還在。
4. 點**回到宮格**（`Esc`）。

**抽檢**

成員的圖很多時不用每張都看：

1. 點**抽檢…**，選擇成員和比例（抽 10% / 20% / 50%），點**開始抽檢**。
2. 軟體從他的待審核圖中隨機抽出這麼多張，逐張審核（操作和上面一樣）。
3. 抽完會顯示合格率。合格率高，點**其餘 N 張全部通過**；合格率低，點**其餘 N 張全部退回**，原因是「抽檢不合格，請自行檢查後重新送出」。也可以先不處理。

也可以照舊在標註頁篩選**待審核**，逐張檢查，點**通過並下一張**（`Enter`）或**退回**。

### 9.5 進度、工作量和紀錄

- **線上**：成員清單中會顯示誰在線上、正在看哪張圖，點一下就能跳過去看。標註員那一列點**看他的圖**，直接到審核頁看他的待審核圖。左側導覽「協作」上的綠點表示協作已開啟。
- **進度與工作量**：依今天 / 近 7 天 / 近 30 天 / 全部，統計每個人的送出張數、標註物件數、被通過和被退回次數、通過率、審核次數、工作時長（兩次操作間隔不超過 5 分鐘的時間累加）。點**匯出 CSV**，用 Excel 開啟，方便外包計件結算。
- **操作紀錄**：誰在什麼時候登入、送出、審核、退回、修改類別、分配任務。點圖片編號可以跳過去看。勾選**包含每次自動儲存**可以看得更詳細。

### 9.6 三種共用方式怎麼選

| | 區域網路 | 線上 · 自建中繼 | 線上 · 巡瞳官方中繼 |
|---|---|---|---|
| 適合 | 同一個公司網路、同一個 Wi-Fi | 外包、在家工作，有自己的雲端伺服器 | 外包、在家工作，沒有伺服器 |
| 成員存取的位址 | `http://你電腦的IP:8765/` | `https://你的中繼/s/編號/` | `https://xuntongai.com/wulabel-relay/s/編號/` |
| 速度 | 最快 | 取決於伺服器頻寬 | 取決於巡瞳伺服器頻寬 |
| 資料經過 | 只在公司內部網路 | 你們自己的伺服器（只轉發、不儲存） | 巡瞳的伺服器（只轉發、不儲存） |
| 需要準備 | 不用 | 一台雲端伺服器，依 `relay/README.md` 安裝中繼服務 | 巡瞳 AI 帳號（在設定中登入） |

- 三種方式下，圖片和標註都只存在你的電腦上，中繼伺服器只負責轉發。
- 線上方式的共用編號固定不變：下次開啟還是同一個位址，成員加入書籤一次就好。
- 你的電腦要一直開著、Wulabel 要一直開著協作，成員才能連上；電腦進入睡眠時成員會看到「發起人不在線上」。建議在電源設定中關閉自動睡眠。

### 9.8 一個完整的例子

以「外包團隊標 2000 張垃圾分類圖，自己團隊審核」為例：

1. **準備**：在 Wulabel 中建立偵測專案，匯入 2000 張圖，在右側新增好類別（資源回收、廚餘、有害垃圾、一般垃圾）。可以先用巡瞳 AI 的專用模型批次預標註一遍（見 16.4），標註員只需要修正錯誤，快很多。
2. **新增成員**：在「協作」頁新增 3 個標註員（外包的小明、小華、阿志）、1 個審核員（自己團隊的小陳），把帳號密碼分別傳給他們。
3. **開啟協作**：選擇「線上 · 巡瞳官方中繼」（或自建中繼），勾選「浮水印」，開啟後把外部網路位址傳給這 4 個人。
4. **分配**：選擇全部標註員，範圍選「還沒分配給人的未標註圖」，不填每人張數，點分配，每人大約 666 張。
5. **標註**：標註員用瀏覽器開啟位址登入，只會看到自己的圖，標完一張按 `Enter` 送出。
6. **審核**：小陳開啟審核頁，點成員「小明」，在宮格中一眼掃過他的待審核圖。沒問題的全選後點「通過」；有問題的勾選起來，點「退回」，勾選「漏標」並寫上「右下角還有一個瓶子」。退回的圖會回到原標註員的「被退回」中，修改好再送出。圖太多時，用「抽檢」抽 20%，合格率高就把其餘的一起通過。
7. **追進度**：你在「協作」頁看誰在線上、誰標得快、誰被退回得多；有人進度落後時，用「收回任務」把他沒做完的圖收回，再分給其他人。
8. **結算**：在「進度與工作量」中選擇時間範圍，點「匯出 CSV」，依送出張數和通過率結算外包費用。
9. **收尾**：全部審核通過後，停止協作，回到 Wulabel 照常訓練、評估、部署。

### 9.9 常見問題

- **成員打不開區域網路位址**：
  - 確認他和你在同一個網路（連的是同一個公司網路或 Wi-Fi，訪客網路通常不通）；
  - 第一次開啟時 Windows 防火牆的提示要點「允許」，如果點了「取消」，要到「Windows 安全性 → 防火牆與網路保護 → 允許應用程式通過防火牆」中勾選 Wulabel；
  - 連接埠被占用時換一個，例如 8766。
- **成員看到「發起人不在線上」**：你的 Wulabel 沒有開啟協作、電腦進入睡眠，或網路中斷了。重新開啟後請他重新整理頁面。
- **外部網路位址一直顯示「正在連線到中繼伺服器」**：
  - 自建中繼：檢查位址和金鑰是否和部署時一樣；
  - 官方中繼：確認已經登入巡瞳 AI 帳號。
- **成員看到「這張圖沒有分給你」**：標註員只能開啟分給自己的圖。請管理員把圖分給他，或換一個人標。
- **兩個人想同時修改同一張圖**：做不到，後開啟的人是唯讀。等前一個人翻到下一張就能修改。
- **批次通過時提示略過了幾張**：有人正在修改的圖、已經不是待審核的圖不會被批次處理。等他修改完送出後再審。
- **成員斷線了，標的會不會遺失**：已經儲存的不會遺失（每次修改都會自動儲存到你的電腦）。網路恢復後，頁面會自動重新連線。
- **能用手機標嗎**：能開啟、能檢視，但畫框還是建議用電腦。
- **最多幾個人**：沒有硬性限制，十幾個人同時標沒問題。人多時你的電腦要一直開著、網路要穩定。
- **停止協作或關閉 Wulabel 會怎樣**：成員會立即中斷連線，看到「發起人已經停止了協作」；已經儲存的標註都在。下次開啟後他們重新整理頁面就能繼續。
- **切換了專案**：協作會自動停止。協作是針對目前開啟的專案。
### 9.10 離線分包

沒有網路，或資料不能離開公司時使用。每個包是一個獨立的 Wulabel 專案，複製給其他人標，標完再合併回來。

**分包：**

1. 在**資料**頁點**管理 → 多人協作（分包、合併回來）**，切換到**分包**。
2. **放在**：選一個資料夾，標註包會建立在這裡。
3. 填寫**標註人員**，每行一個（或用逗號隔開），例如「小明」「小華」。幾個人就分幾個包。
4. 選擇範圍：**只分配未標註的圖** / **還沒審核的**（未標註 + 待審核）/ **全部**（略過的除外）。
5. 勾選**帶上現有的標註**：模型預標註過的圖，讓標註人員在上面修改，更快。
6. （選用）勾選**給圖片打馬賽克**，把人臉、車牌等隱私區域打上馬賽克後再傳出去（見 13.2）。
7. 點**分成 N 個包**。完成後會自動開啟存放資料夾。把包資料夾複製給對應的人，對方用 Wulabel **開啟專案**就能標。

**合併回來：**

1. 把標完的包資料夾複製回來。
2. 開啟**多人協作**，切換到**合併回來**（或在「分出去的包」清單中直接點那個包的**合併**）。
3. 選擇包資料夾。選項：**衝突時用包裡的覆蓋**（分包後原專案也改過的圖，預設不覆蓋）、**標註人員在包裡新加入的圖也一併匯入**。
4. 點**合併**，下方會顯示合併進度。結果會顯示合併了幾張、幾張沒有變化、新加入幾張、衝突幾張。有衝突時點**逐張檢視**。

## 10. 訓練

點左側的**訓練**。第一次訓練前要先裝好訓練環境（見第 2 章），沒裝時頁面會提示**前往安裝**。

### 10.1 設定訓練參數

頁面上方會顯示「可訓練圖片」的數量（已標註的圖；團隊協作時是待審核 + 已通過）。還沒劃分的圖，開始訓練時會依 8:2 自動分到訓練集和驗證集；分過的圖不會自己改變，前後幾次訓練可以直接比較。

點「可訓練圖片」旁邊的**檢視和調整**，可以查看每張圖分在哪裡：

- **訓練集**：模型從這些圖中學習；
- **驗證集**：不參與學習，每訓練一輪用它評估一次，挑出效果最好的那一輪儲存；
- **測試集**：訓練時完全不使用，訓練完後在「評估」頁單獨評分，最接近模型上線後的真實效果。

在對話框中點圖片選取（按兩下開啟標註），點**移到訓練集 / 移到驗證集 / 移到測試集**手動調整；下方可以修改訓練 / 驗證 / 測試的比例，點**現在分配未劃分的 N 張**，或**全部重新劃分**（之前的劃分會被打亂，前後訓練無法直接比較）。訓練集被移空時會提示，無法開始訓練。

| 選項 | 說明 |
|---|---|
| 起點 | 預設「從預訓練權重開始（從頭訓練）」。補充新資料後可以選「接續『某次訓練』繼續訓練」，比從頭訓練更快也更穩；類別有變動時，分類部分會重新學習。 |
| 模型 | 依專案任務列出，標示「推薦」的是依這台電腦推薦的：偵測專案沒有獨立顯示卡時推薦 YOLOX-Tiny，4GB 以上顯示記憶體推薦 YOLOX-S，8GB 以上推薦 YOLOX-M，Mac 推薦 YOLOX-S。新建立的偵測專案預設 YOLOX-S。接續訓練時沿用那次的模型。 |
| 訓練輪數 | 資料越少需要的輪數越多，一般 20~50。 |
| 輸入尺寸 | 目標小（遠處的人、安全帽）時用大尺寸，速度會變慢。分類一般用 224。 |
| 批次大小 | 顯示記憶體不足而報錯時請調小。 |
| 訓練資料 | 「目前資料」或某個資料集版本。 |
| 裝置 | 「自動（有顯示卡就用顯示卡）」或「只用 CPU」。 |
| 只用審核通過的圖片 | 團隊協作時才有：勾選後只用「已通過」的圖訓練，待審核的這次不參與。 |

輸入尺寸、批次大小、資料擴增、裝置、只用審核通過的圖片（團隊協作時才有）這幾項放在「進階設定」中，預設收合，點「進階設定」展開；軟體會記住你上次是展開還是收合。

訓練時顯示記憶體不足（v0.4.2 起）：軟體會自動把批次大小減半、從頭重新訓練，一直減到 1 為止，介面上會提示一次，訓練紀錄中也會寫「批次大小 2（顯示記憶體不足，從 8 自動調小）」。批次大小越小訓練越慢，顯示記憶體真的不夠時，也可以換小一級的模型或調小輸入尺寸。

可選的模型：

| 任務 | 模型 | 特點 |
|---|---|---|
| 偵測 | YOLOX-Nano | YOLO 系列最輕量的一級，適合 CPU、手機和效能很弱的邊緣裝置；預設 416 輸入 |
| 偵測 | YOLOX-Tiny | 很輕量，適合 CPU 和 NPU 邊緣運算盒即時推論；預設 416 輸入 |
| 偵測 | YOLOX-S | 速度和精度最平衡，大多數專案先用它 |
| 偵測 | YOLOX-M | 精度更高，建議 6GB 以上顯示記憶體 |
| 偵測 | YOLOX-L | 精度最高、最慢，建議 8GB 以上顯示記憶體 |
| 偵測 | Faster R-CNN MobileNetV3 | 速度快、占用顯示記憶體少，適合入門和沒有獨立顯示卡的電腦 |
| 偵測 | Faster R-CNN ResNet50 | 精度更高、較慢，建議 6GB 以上顯示記憶體 |
| 偵測 | RetinaNet | 單階段，精度接近 Faster R-CNN，轉 TensorRT 更順利 |
| 偵測 | FCOS | 單階段、無錨框，結構簡單，適合部署 |
| 偵測 | SSDLite | 單階段、很輕量，適合 CPU 和 NPU 邊緣裝置；固定 320 輸入，小目標表現普通 |
| 分割 | Mask R-CNN | 實例分割，建議 6GB 以上顯示記憶體 |
| 關鍵點 | Keypoint R-CNN | 人體 17 點能用上 COCO 預訓練 |
| 分類 | MobileNetV3 / EfficientNet-B0 / ResNet50 | 從輕快到更準 |

### 10.2 YOLOX 模型

YOLOX 是曠視開源的 YOLO 系列偵測模型（Apache-2.0，可以放心商用），和巡瞳 AI 平台的專用模型是同一個系列。

- **預訓練權重**：第一次訓練時會自動下載官方 COCO 預訓練權重（Nano 約 8MB、S 約 70MB、L 約 430MB），先從官網下載，失敗再從 GitHub 下載；下載過一次之後就不用再下載。
- **資料擴增**：採用 YOLOX 官方的做法，Mosaic 拼接、MixUp、隨機縮放旋轉、色彩抖動、水平翻轉、多尺度訓練都會自動開啟，最後約 10% 的輪數會關閉強擴增收尾。所以選擇 YOLOX 時不會顯示下面的「資料擴增」設定。
- **訓練輪數**：YOLOX 需要的輪數比 Faster R-CNN 多一些，建議 50 輪以上；資料少（幾百張）時 100 輪左右。
- **學習率**：會依批次大小自動換算，不用設定。
- **輸入尺寸**：Nano、Tiny 預設 416，S、M、L 預設 640，可以修改，會取 32 的倍數。
- **為什麼不是 YOLOv5 / v8 / v11**：它們採用 AGPL-3.0 授權，用在商業產品中有限制；YOLOX 是 Apache-2.0，和 Wulabel 一樣。在其他地方訓練好的 YOLOv5 / v8 / v11 模型仍然可以透過「匯入外部模型」匯入，用來預標註和評估。

訓練好的 YOLOX 模型和其他模型的用法一樣：評估、模型預標註、誤報測試、即時驗證、匯出部署、上傳巡瞳都支援。

### 10.3 資料擴增

訓練時隨機改變圖片，讓模型看過更多樣貌，資料少時效果明顯。

1. 在「資料擴增」中選擇預設組合：**關閉**、**預設**、**輕度**、**標準**、**強（資料少時）**。
2. 想細部調整就展開，修改**左右翻轉**、**上下翻轉**、**亮度**、**對比度**、**飽和度**、**色調**、**模糊**（模擬對焦不準、動態模糊）、**雜訊**（模擬夜間低照度）、**多尺度**（對遠近大小變化大的目標有幫助）、**旋轉**、**隨機裁切**。修改後預設組合會顯示為「自訂」。
3. 點**預覽效果**，查看幾張圖隨機擴增後的樣子（每張圖隨機變化兩次，紅框是跟著變換後的標註位置），確認不會太誇張。

### 10.4 開始訓練、查看過程

1. 開始前看一下按鈕上方的「每輪約 N 步 · 共約 M 步」。圖太少（訓練集不到 20 張）或總步數太少（不到約 300 步）時，點**開始訓練**會先跳出提醒：這樣訓練多半學不到東西，指標可能一直是 0。建議多標一些圖，或依提示把訓練輪數加大，資料很少時也可以先用 Faster R-CNN MobileNetV3。真的只想試一下就點**仍然開始**。驗證集只有一兩張時也會提醒：指標波動會很大、不可信。
2. 點**開始訓練**。會先準備訓練資料（圖多時按鈕下方會顯示「正在準備訓練資料 N/M」）；第一次使用某個模型時會下載預訓練權重，訓練頁顯示「正在下載預訓練權重 檔名：已下載 / 共多少 MB · 速度」，右下角也有進度列。網路斷了會接著下載，下載過一次之後就不用再下載。
3. 訓練中會顯示「第 N / M 輪 · 本輪進度 · loss · 預估剩餘時間」，下方有**損失 loss** 曲線、**驗證集**指標曲線和**日誌**。
   - 日誌上方的「關鍵資訊」固定顯示日誌開頭幾行：使用的裝置、訓練集和驗證集張數、預訓練權重有沒有載入成功。出錯、警告的行會標成黃色。
   - 往上捲動日誌時不會被拉回底部；停在底部時會跟著捲動。
   - 沒下載到預訓練權重（多半是網路問題），或指標連續 10 輪都是 0 時，頁面頂端會出現黃色提示條，寫著可能的原因和該怎麼做。
4. 想提前結束時點**停止**，確認後目前這批算完就停。已訓練完的輪次和目前最好的模型都會保留。
   - 訓練還在進行時關閉軟體，會先跳出確認「訓練還沒結束，關閉軟體會中斷訓練」，避免誤關。
5. **從中斷點繼續**：訓練被停止、軟體被關閉或因出錯中斷後，這筆紀錄上會出現**繼續訓練**按鈕。點它會在同一筆紀錄上，從最後訓練完的那一輪接著跑剩下的輪數，曲線和日誌接在後面，不用從頭再來。訓練正常跑完後，中斷點會自動刪除（大模型的中斷點有幾百 MB）。
   - 和起點中的「接續『某次訓練』繼續訓練」不同：那個是拿某次訓練好的模型當起點、開始一次新的訓練，適合補充新資料之後再訓練。
6. 訓練結束時會跳出系統通知、工作列圖示會閃一下（軟體在背景也能知道）；軟體右下角會提示「訓練完成」，並附上最好的指標和評價（差 / 普通 / 可用）：
   - 效果不錯時，可以直接點**前往評估**、**前往預標註**；
   - 效果很差時，會提示先點**查看原因**回訓練頁看看；
   - 訓練失敗時，不在訓練頁也會跳出提示，點**查看錯誤**查看。
7. 訓練出錯時，常見的錯誤會翻譯成白話，並提供修復按鈕：顯示卡驅動程式和 PyTorch 對不上（**前往設定更換 PyTorch 版本**）、顯示記憶體或記憶體不足（**改用 CPU**）、磁碟已滿、網路下載失敗、找不到圖片檔案（**前往資料頁**）。完整的錯誤訊息點**詳細資訊**展開。

### 10.5 訓練紀錄和訓練比較

每次訓練都會自動存成一筆**訓練紀錄**，列出時間、模型、資料、輪數、指標、狀態（訓練中 / 完成 / 已停止 / 失敗）。每一筆可以：

- **查看評估**（開啟的就是這一次訓練的評估）、**匯出 ONNX**（匯出時會顯示進度）、**開啟訓練資料夾**、刪除。還在訓練中的紀錄要等訓練完才能查看評估、部署。
- 已停止、中斷或失敗的紀錄有**繼續訓練**（見 10.4）。

**批次刪除**：在訓練紀錄中勾選幾筆，點**刪除所選（N）**，確認後一起刪除（模型檔案、日誌和這次訓練用的資料集副本都會刪除，無法還原）。訓練中的紀錄無法勾選。

**訓練比較**：

1. 在訓練紀錄中**勾選兩次以上**的訓練（最多同時比較 8 次）。
2. 點**比較所選（N）**。
3. 比較視窗中：參數和資料並排（不同的地方以粗體標示）、各項指標、損失曲線疊在一起，各類別結果會標出最好的一次。

### 10.6 匯入外部模型

在其他地方（例如 Ultralytics YOLO）訓練好的偵測模型，匯出成 ONNX 後可以匯入，用來預標註、健檢、評估和誤報測試（不能接續訓練或部署）。目前只支援偵測專案。

1. 在訓練紀錄上方點**匯入外部模型**。
2. 點**選擇 .onnx 檔案**。
3. 軟體會自動辨識：
   - **格式**：YOLOv8 / v11（Ultralytics）、YOLOv5 / v7、YOLOv10 等端到端模型、YOLOX、RT-DETR、DETR / RF-DETR、Wulabel 匯出的模型。辨識不對可以手動修改；
   - **輸入尺寸**；
   - **類別名稱**（每行一個，順序要和模型一致）。把英文類別名稱改成專案中的類別名稱就能對應上，例如把 person 改成「人」。
4. **要使用的類別**：沒勾選的類別在預標註時不會加進來；和專案同名的類別預設會勾選。
5. 點**匯入**。訓練紀錄中會多一筆「…（外部）」。

## 11. 評估

點左側的**評估**，選擇一筆訓練紀錄（從訓練頁點「查看評估」進來時，選好的就是那一次）。還在訓練中的紀錄會顯示「訓練中」，訓練完才能選。

### 11.1 查看指標

- 頂端會說明這次評估用的是哪一輪的最佳模型，可以在**驗證集**和**測試集**之間切換。
- 最上面一行是**結論**：依主指標給出「差 / 普通 / 可用」（偵測類看 mAP50，低於 0.3 為差、0.3~0.6 為普通、高於 0.6 為可用；分類看準確率，低於 0.6 為差、0.6~0.85 為普通、高於 0.85 為可用），並指出**最差的類別**。旁邊是下一步的按鈕：查看漏檢的錯誤案例、把錯誤案例拿去標註、補充資料後再訓練 / 換大模型；效果可用時有**前往部署**。評估的圖少於 10 張時會提醒「指標波動大」。
- 偵測、分割、關鍵點專案：**mAP50**（最常用的偵測指標）、**mAP50-95**（對框的準確度要求更高）、**精確率**（回報的框中正確的比例，偏低表示誤報多）、**召回率**（真實目標被找到的比例，偏低表示漏檢多）。分割、關鍵點依目標框計算。
- 分類專案：**準確率**、**宏平均 F1**、平均精確率、平均召回率。
- 滑鼠停在指標上會顯示解釋。
- **各類別**表格：每個類別的圖片數、真實框數和各項指標。

### 11.2 混淆矩陣

列是真實類別，欄是模型預測。對角線是分對的，其他格子是把某類誤判成另一類。最後一欄「背景」是漏檢，最後一列「背景」是誤報。滑鼠停在格子上會顯示具體數字。

### 11.3 錯誤案例

- 列出有問題的圖，可以依**有漏檢**、**有誤報**、**類別錯誤**篩選。
- **點一張錯誤案例**會直接跳到標註頁檢查和修改。改完再訓練，形成閉環。

### 11.4 信心值閾值

部署時警報要用多少閾值，看這裡：

1. 軟體會推薦 F1 最高的閾值，並顯示這個閾值下的精確率、召回率。
2. 曲線顯示精確率、召回率、F1 隨閾值的變化。**拖曳滑桿**查看不同閾值的效果：找對幾個、誤報幾個、漏掉幾個。
3. 怎麼選：誤報多就調高閾值；漏報多就調低。
4. 下方表格是**各類別的建議閾值**。
5. 建議閾值會自動帶到「部署」頁的即時驗證和推論服務包，作為預設的信心值閾值。

### 11.5 用目前資料評估

補充資料、修改標註後，不用重新訓練，點**用目前資料評估**，就會用現在的已標註資料（驗證集 / 測試集）重新計算一次指標，介面上會顯示「正在評估驗證集 N/M 張」。匯入的外部模型也用這個方式評估。

### 11.6 誤報測試

用一段**不該發出警報**的影片（沒有目標，或只有容易認錯的東西，例如空曠的通道、晚上的廠區）測試模型會誤報幾次：

1. 在「誤報測試」中點**選擇影片檔案**，或填寫 `rtsp://` / `http(s)://` 位址。
2. 設定：**每秒偵測 N 個影格**、**連續 N 次偵測到才算一次警報**、**測試 N 分鐘**（影像串流用）。
3. 點**開始測試**，隨時可以點**提前結束**。
4. 結果：測試了多久、警報幾次、**換算每小時**幾次，依類別統計；下方是**誤報的畫面**（紅框是模型回報的，只保留最近 60 張）。
5. 點**把這些影格加進資料集當作負樣本**：會以「沒有目標」的圖加入，下次訓練時模型會學著不在這類畫面上發出警報。如果其中有真正的目標，加入後到標註頁補上標註。

### 11.7 匯出交付報告

1. 點**匯出報告**，選擇儲存位置（預設檔名為「專案名稱_訓練名稱_模型報告.html」）。
2. 報告是一個 HTML 檔案，包含資料概況、訓練參數、指標、曲線、混淆矩陣、錯誤案例、建議閾值和誤報測試結果，用瀏覽器直接開啟，可以交給客戶驗收。

## 12. 模型預標註和挑圖

### 12.1 用自己的模型預標註

1. 到**標註**頁，在右側「AI 輔助」中選擇**我的模型**，從下拉選單選一個訓練好的模型（會顯示名稱和 mAP50 / 準確率）。
2. 調整**信心值**。
3. 單張：按 **P** 或點**預測本圖 (P)**。
4. 批次：點**批次預標註**，替一批未標註的圖都標上。對話框會馬上關閉，進度條在右側，可以邊執行邊標註；想中途停下就點進度條旁邊的**停止**，已經標好的會保留。
5. 預標註的框是虛線，檢查、修改好後按 **Enter**（完成並下一張），這張就算已標註。分類專案會顯示「模型的候選」，前 3 個類別點一下就能採用。

標得越多 → 模型越準 → 預標註越省事。

### 12.2 挑選最值得標註的圖

有了初版模型後，與其隨便標，不如先標模型最拿不準的圖：

1. 在**資料**頁點**管理 → 挑選最值得標註的圖（用模型）**。
2. 選擇模型，填寫**挑選 N 張**，點**開始挑選**。
3. 結果會依「拿不準」程度從高到低排列。
4. 點**依這個順序去標註**，標註頁只會顯示這批圖（頂端篩選會多一個「模型挑選」）。標完點它旁邊的 × 回到全部圖片。

## 13. 匯出資料集（含去識別化）

### 13.1 匯出

1. 在**資料**頁點**匯出資料集**。
2. **格式**（依專案任務）：
   - 偵測：YOLO、COCO、VOC；
   - 分割：YOLO-seg、COCO、VOC（只有外接框）；
   - 關鍵點：YOLO-pose、COCO 關鍵點、VOC（只有目標框）；
   - 分類：分類資料夾（train/類別/圖片.jpg）。
3. **範圍**：未標註和已略過的圖不會匯出；標為「沒有目標」的圖會作為負樣本匯出。團隊協作時還可以勾選**只匯出審核通過的圖片**。
4. **訓練 / 驗證 / 測試 比例（%）**：還沒劃分的圖會依這個比例分配。想全部重新分配，點**全部重新劃分**（之前的訓練結果將無法和新劃分直接比較）。
5. **匯出到**：點**瀏覽**選擇位置，**資料夾名稱**會自動產生，可以修改（修改過之後換格式也不會被覆蓋）。
6. 點**匯出**。完成後會顯示匯出了多少圖、多少標註、各劃分多少張，點**開啟資料夾**直接查看。

匯出某個資料集版本：在資料集版本清單中點**匯出這個版本**，劃分會固定為版本中的劃分。

### 13.2 去識別化

匯出資料集、匯出版本、分包時，都可以勾選**給圖片打馬賽克**：

1. **依類別**：在下拉選單中選擇要打馬賽克的類別，例如你標的「人臉」「車牌」。名稱中含「臉」「車牌」的類別會預設選取。
2. **自動尋找**：勾選**自動尋找人臉**、**自動尋找車牌**，軟體會用開放詞彙偵測模型找出來（第一次需要下載模型；有 GPU 會快很多）。
3. **方式**：**馬賽克**、**模糊**、**塗黑**。
4. 匯出時會多一個「去識別化」階段的進度。

去識別化只修改匯出的副本，專案中的原圖不動。自動尋找可能會漏掉很小、側臉、遠處的目標，重要資料請抽查。

## 14. 部署

點左側的**部署**，選擇一個訓練好的模型。頁面有四個分頁：**即時驗證**、**匯出模型**、**推論服務包**、**現場回流**。

### 14.1 即時驗證

接上攝影機或影片，現場查看模型效果：

1. 選擇**影像串流**或**本機影片**。
2. 填寫影像串流位址：RTSP 攝影機（例如 `rtsp://admin:密碼@192.168.1.64:554/Streaming/Channels/101`），或 HTTP-FLV、HLS（m3u8）、http 上的 MP4 位址；也可以點**選擇影片檔案**。
3. 點**開始**。啟動時會依序顯示「準備執行環境…」「載入模型…」「連線影像來源…」，出現畫面後會即時畫出結果：偵測模型畫框，分割模型畫輪廓，關鍵點模型畫點和骨架，分類模型在左上角顯示機率最高的幾個類別；頂端顯示解析度，以及是用顯示卡還是 CPU 推論。
4. 拖曳**信心值**滑桿調整閾值。預設使用評估頁的建議閾值，修改過之後點「使用推薦值 0.xx」可以改回來。
5. 看到漏檢、誤報的畫面時，點**截圖加入資料集**，圖會以「未標註」加入，標註後再訓練。
6. 點**停止**結束。

### 14.2 匯出模型

1. 選擇格式：
   - **ONNX（動態尺寸）**：通用格式，onnxruntime 在 Windows / Linux / ARM 上都能執行；
   - **ONNX（固定尺寸）**：輸入固定為 [1,3,N,N]，給需要固定形狀的推論框架使用；
   - **OpenVINO**：Intel CPU、內顯、工業電腦加速，直接在軟體中轉換並驗證（首次使用會自動安裝 OpenVINO；安裝失敗時只略過這一種，其他格式照常匯出）；
   - **TensorRT 轉換包**：NVIDIA 顯示卡、Jetson，需要在目標裝置上執行腳本產生引擎；
   - **RKNN 轉換包**：瑞芯微 RK3588 / 3568 等，需要在 Ubuntu 上執行腳本轉換。
2. 需要固定尺寸時設定尺寸。
3. 選擇**匯出到**的位置、**資料夾名稱**，點**匯出**。預設只勾選 ONNX。匯出時會顯示「第幾 / 共幾步」和目前的格式，完成後每種格式會顯示成功或失敗，點**開啟**查看。

內建的 Faster R-CNN 是兩階段模型，NPU（RKNN）和舊版 TensorRT 對它的支援有限，轉換可能失敗或速度不理想；要用在這類裝置上，建議訓練 YOLOX 或其他單階段模型（RetinaNet、FCOS、SSDLite）。ONNX 和 OpenVINO 可以放心使用。

YOLOX 模型匯出時：ONNX（動態尺寸）、OpenVINO 和其他模型一樣，模型中已經做好縮放、解碼和重複框過濾（NMS），直接輸出結果；ONNX（固定尺寸）、TensorRT、RKNN 轉換包使用的是 YOLOX 官方格式（輸入 BGR 0~255、左上角補 114，輸出未做 NMS），運算子都是一般卷積，NPU 和 TensorRT 都能完整執行，後處理請見轉換包中的 README。

分割、關鍵點模型（Mask R-CNN、Keypoint R-CNN）也能匯出 ONNX、OpenVINO 等格式：分割模型多一個輸出 `masks`（每個目標的遮罩機率，大於 0.5 的是目標），關鍵點模型多 `keypoints`（每個點的 x、y、可見性）和 `keypoints_scores`。即時驗證和推論服務包對偵測、分割、關鍵點、分類模型都支援。

### 14.3 推論服務包

產生一個帶到現場電腦就能執行的推論服務，偵測、分割、關鍵點、分類模型都支援：

1. **影像串流**：填寫名稱和位址（`rtsp://…`、`http(s)://…` 的 FLV / m3u8 / MP4，或影片檔案路徑），點**新增一路**可以加入多路。
2. **偵測間隔（秒）**：每路影片每隔多久偵測一個影格。
3. **警報規則**：
   - **警報類別**（不選表示所有類別都發出警報）；
   - **信心值閾值**（預設使用評估頁的建議閾值）；
   - **重複過濾間隔（秒）**：同一路影片同一類別，這段時間內只發出一次警報；
   - **生效時段**：全天，或如 `07:00-19:00`；
   - **儲存警報截圖（含框）**。
4. **警報推播**：
   - Webhook：發出警報時 POST JSON 到這個位址，可選擇**附上截圖（base64）**；
   - MQTT：伺服器位址、主題、使用者名稱、密碼（不填則不推播）。
5. **服務**：**HTTP API 連接埠**；**用顯示卡推論**（現場電腦要安裝 onnxruntime-gpu，否則會自動改用 CPU）。
6. **現場回流**：模型拿不準（信心值在設定區間內）的畫面會存到服務包的 `reflux/` 資料夾。
7. 選擇**產生到**的位置，點**產生推論服務包**，產生時會顯示「第幾 / 共幾步」。
8. 把整個資料夾複製到現場電腦：Windows 按兩下 `run.bat`，Linux 執行 `sh run.sh`。設定在 `config.json`，說明見 `README.md`。現場電腦不需要 PyTorch 和顯示卡，只依賴 onnxruntime、OpenCV、numpy；第一次執行時需要先安裝 Python 3.9 以上版本，並連網安裝這幾個相依套件，安裝到一半失敗的話，下次執行時會自動重新安裝。

### 14.4 現場回流

1. 服務包在現場執行時，會把模型拿不準的畫面存到 `reflux/` 資料夾。
2. 定期把 `reflux/` 複製回來，在**現場回流**分頁點**匯入現場回流圖片**，選擇這個資料夾。匯入時會顯示進度，可以停止。
3. 點**前往標註這批**，只把剛匯入的這批圖送到標註頁，用模型預標註後再修正。
4. 重新訓練，再產生新的服務包，取代現場的 `model.onnx`。模型會越用越準。

### 14.5 上傳到巡瞳 AI 平台

不想自己部署服務的話，可以把模型上傳到巡瞳 AI 平台，在平台上接攝影機、設定警報（目前支援物件偵測模型）：

1. 先在**設定**中設定好巡瞳 AI（見 2.3）。
2. 在**部署 → 匯出模型**最下方的「上傳到巡瞳 AI 平台」，修改一下**模型名稱**，點**上傳**。還沒匯出 ONNX 的會先自動匯出。
3. 上傳後平台需要驗證幾秒到一分鐘，會顯示「平台正在驗證」，驗證通過後變成「驗證通過」（失敗會顯示原因）。評估頁算出的建議閾值會一起上傳，作為平台上的預設閾值。
4. 點**開啟控制台**，到「自訂模型」中點**啟用**，就能接攝影機、設定警報了。
5. 下方的「平台上的自訂模型」會列出已上傳的模型、驗證狀態和是否啟用。沒有開通託管的帳號只能放 1 個模型，要上傳新版本時請先**刪除**舊的。
6. 平台上產生的警報圖片可以再拉回來標註（見 4.7）。

## 16. 巡瞳 AI 使用指南

巡瞳 AI（[xuntongai.com](https://xuntongai.com)）是一個 AI 辨識平台：有現成的專用辨識模型（垃圾分類、安全帽、煙火等）和大模型辨識，還能託管你自己的模型、接攝影機、推播警報。Wulabel 和它串接後，**標註、訓練、上線、現場回流**可以連成一個閉環。前面各章分散介紹過用法，這一章集中說明清楚。

Wulabel 中用到巡瞳 AI 的地方：

| 在哪 | 做什麼 | 見 |
|---|---|---|
| 設定 → 巡瞳 AI | 登入帳號、查看額度 | 16.1、16.2 |
| 標註頁 → AI 輔助 → 巡瞳 AI | 用專用模型 / 大模型 / 依專案類別自動標註 | 16.3–16.5 |
| 標註頁 → AI 輔助 → 辨識規則 | 寫辨識說明、和 AI 聊怎麼辨識、同步到平台 | 16.5 |
| 部署 → 匯出模型 → 上傳到巡瞳 AI 平台 | 把訓練好的模型放到平台上使用 | 16.6 |
| 資料 → 更多匯入方式 → 從巡瞳 AI 拉取警報圖片 | 把現場的誤報、漏報拉回來再標註 | 16.7 |
| 協作 → 線上 · 巡瞳官方中繼 | 讓外部網路的成員連進來一起標 | 16.8 |

### 16.1 登入帳號

1. 開啟**設定**，在「巡瞳 AI」這一欄點**登入巡瞳 AI 帳號**。
2. 瀏覽器會開啟巡瞳 AI 的網頁：
   - 還沒登入就先登入（和平常登入巡瞳一樣，驗證碼、簡訊都可以）；
   - 核對網頁上的確認碼和 Wulabel 視窗中的是否相同，點**允許**。
3. 回到 Wulabel，幾秒後會顯示**已登入**、帳號名稱和方案、剩餘額度，以及可用的辨識方式。

說明：

- 不用到控制台建立、複製 API Key：登入時平台會發給這台電腦一個專用 Key，名稱是「Wulabel · 電腦名稱」，在巡瞳控制台的「API Key」頁能看到，也能停用。
- 同一台電腦重新登入時，會自動換掉舊的 Key。個人帳號最多 2 個 Key，滿了網頁上的「允許」會無法點選，請到控制台停用一個不用的 Key 再試。
- 瀏覽器沒有自動開啟：點視窗中的**重新開啟**，或複製位址自己開啟。登入碼 10 分鐘內有效。
- **登出**：本機的 Key 會被刪除，登入時發的 Key 會在平台上停用。
- 已經有 API Key，或巡瞳是私有化部署的：點**進階：手動填寫 API Key、私有化部署的平台位址**。

### 16.2 額度和費用

- 設定頁會顯示每種額度剩多少、什麼時候到期：大模型辨識、專用模型辨識、自帶模型辨識、加值包等，依你的方案而定。
- 怎麼計算：辨識一張圖算 1 張。批次預標註前會提示總張數；和 AI 聊辨識規則每一輪算 1 張大模型額度。
- 只會用到你自己帳號的額度；協作成員用 AI 聊天時，使用的是發起人的額度（發起人可以在協作頁關閉「成員可以使用 AI 輔助」）。
- 額度用完時會提示「額度不足」，批次預標註會停下來，已經標好的會保留。

### 16.3 四種辨識方式怎麼選

在標註頁右側「AI 輔助」中選擇**巡瞳 AI**，「選擇辨識模型」下拉選單中有：

| 辨識方式 | 適合 | 速度 | 額度 |
|---|---|---|---|
| 專用模型（如垃圾分類、安全帽） | 專案的類別和平台現成的模型對得上 | **最快**，批次時 8 張一批、兩批同時傳送 | 專用模型辨識 |
| 你上傳並啟用的自帶模型 | 自己訓練過、上傳到平台上的模型 | 同上 | 自帶模型辨識 |
| 依專案類別辨識（推薦） | 平台沒有對得上的模型；只想找專案中這幾類 | 一張一張，比較慢 | 大模型辨識 |
| 大模型通用辨識 | 依安全隱患大類（消防、電氣、環境衛生等）尋找 | 一張一張 | 大模型辨識 |

選法很簡單：**有對得上的專用模型就用專用模型**（又快又準）；沒有就用**依專案類別辨識**，把每個類別的辨識說明寫清楚（16.5）。

### 16.4 用專用模型批次自動標註

以垃圾分類為例：

1. 建立偵測專案，匯入圖片。類別可以先不建立：模型辨識出的類別名稱（如「可回收物」）在專案中沒有時會自動新建。
2. 開啟標註頁，右側「AI 輔助」選擇**巡瞳 AI**，模型選擇**垃圾分類**。
3. 調整**信心值**：先用預設值，框太多就調高，漏得多就調低。
4. 先按 `P` 標註目前這張看看效果，滿意了再點**批次預標註**。會對所有「未標註」且還沒有標註的圖逐批辨識，進度列會顯示進度。
5. 辨識出的框是虛線（來源「巡瞳」）。逐張檢查：錯的刪掉、偏的拖正、漏的補上，按 `Enter`（完成並下一張）。
6. 想更快：標了幾百張後，用這些資料訓練自己的模型（第 10 章），之後在本機預標註，不花額度。

批次處理時遇到「呼叫太頻繁」會自動放慢並重試，不會重複扣額度；額度不足、模型未開通這類錯誤會停下來，並告訴你已經標了幾張。

### 16.5 依專案類別辨識和辨識規則

平台沒有對得上的模型時，用「依專案類別辨識」：平台只找你專案中的類別，類別名稱原樣對應，**清單以外的東西一律不回報**。效果好不好，關鍵在於你有沒有把規則說清楚。

**寫辨識說明：**

1. 在類別旁的編輯按鈕中填寫**辨識說明**：這個類別具體指什麼、什麼算 / 不算。例如：
   - 未戴安全帽：頭上沒有安全帽的人；戴了帽子但沒繫帶也算；只框頭部和上半身。
   - 電動車：兩輪電動機車、電動自行車；自行車、機車不算。
2. 或在「AI 輔助」標題旁點**辨識規則**，在**目前規則**中集中修改**整體規則**（適用於所有類別，例如「只看畫面下半部的通道，忽略海報和螢幕中的內容」）和每個類別的說明，點**儲存規則**。

**和 AI 聊：**不知道怎麼寫規則，就在**辨識規則 → 和 AI 聊**中用白話說明：

- 「戴了帽子但沒繫帶的也算未戴安全帽」
- 「反光衣不算安全帽」
- 「這張圖左邊那個人為什麼沒認出來？」

預設會附上目前這張圖，AI 回答後會依新規則在這張圖上試辨識。AI 建議修改規則時會列出具體內容，點**採用這些規則**才會儲存；試辨識有結果時，點**把試辨識的框加到這張圖**直接使用。

**同步到巡瞳平台（選用）：**在「目前規則」最下方點**同步到巡瞳平台**，規則會存到平台上。預設不啟用，不影響平台目前的辨識。

想讓巡瞳平台自己的辨識（抓拍、警報推播）也只回報你專案中的類別，就開啟**平台辨識也使用這套規則**。注意：開啟後整個巡瞳帳號的辨識都會依照這套規則，適用場景可以在巡瞳控制台的「辨識規則」頁調整。

綁定後，每次儲存或採用規則都會自動同步內容，但不會改動你在控制台設定的啟用狀態和場景。不想同步時點**解除綁定**，平台上的規則不會刪除。

**限制：**最多 30 個類別、類別名稱不超過 30 個字；整體規則最多 1000 字，每個類別的辨識說明最多 500 字；每個巡瞳帳號最多 20 套規則。

### 16.6 把訓練好的模型上傳到巡瞳

1. 在 Wulabel 中訓練一個**物件偵測**模型（巡瞳目前只接受偵測模型）。
2. 到**部署 → 匯出模型**，在最下方「上傳到巡瞳 AI 平台」修改模型名稱，點**上傳**。還沒匯出 ONNX 的會先自動匯出；評估頁的建議閾值會一起上傳。
3. 平台驗證需要幾秒到一分鐘：會顯示「驗證中」→「驗證通過」（或「驗證失敗」和原因）。
4. 點**開啟控制台**，到「自訂模型」中點**啟用**。啟用後就能在平台上接攝影機、設定警報，標註頁的模型清單中也能選到它。
5. 下方的「平台上的自訂模型」會列出上傳過的模型、驗證狀態、是否啟用。沒有開通託管的帳號只能放 1 個模型，上傳新版本前請先**刪除**舊的。模型檔案最大 200MB。

### 16.7 拉回現場警報圖片，持續改進

模型上線後，現場的警報截圖中有誤報、漏報，正是最值得補充的資料：

1. **資料 → 更多匯入方式 → 從巡瞳 AI 拉取警報圖片**。
2. 選擇時間範圍（最近 1 / 3 / 7 天）、哪個模型的警報、最多幾張。預設勾選**將平台辨識出的框作為預標註**。
3. 拉回的圖在專案的 `images/xuntong_時間/` 資料夾，框是虛線（來源「巡瞳」）。
4. 逐張修改：誤報的框刪掉（畫面中本來就沒有目標的圖直接按 **Enter** 完成，作為負樣本），漏的補上。
5. 重新訓練、評估，再上傳新版本，取代平台上的舊模型。

注意：平台的警報圖片保留 7 天，記得定期拉取；只有設定了推播管道的帳號才會產生警報紀錄。

這就是閉環：**標註 → 訓練 → 上傳巡瞳 → 現場警報 → 拉回修正 → 再訓練**，模型越用越準。

### 16.8 協作中的巡瞳 AI

- **官方中繼**：在協作頁的共用方式選擇**線上 · 巡瞳官方中繼**，外部網路的成員透過巡瞳的伺服器連進來，不需要自己的伺服器。需要先登入巡瞳帳號。每個帳號最多同時開啟 3 個共用；圖片和標註經過巡瞳伺服器轉發、不儲存。資料敏感的專案請用區域網路或自建中繼。
- **成員能用什麼**：成員不能直接用巡瞳 AI 預標註（會花你的額度）；開啟「成員可以使用 AI 輔助」時，成員可以開啟辨識規則和 AI 聊（使用你的額度）。能不能修改規則則依「成員可以新增、修改類別」開關而定。

### 16.9 常見問題

- **點登入後瀏覽器沒有反應**：點視窗中的**重新開啟**，或複製位址到瀏覽器中開啟。公司電腦禁止自動開啟瀏覽器時也這樣處理。
- **網頁上的「允許」點不了**：帳號的 Key 數量已滿，請到巡瞳控制台「API Key」頁停用一個不用的。
- **顯示「連線失敗」**：
  - 查看提示中的原因；
  - 手動填入的 Key 請檢查是否完整複製（以 `sk-live-` 開頭）、在控制台中是否已啟用、有沒有設定 IP 白名單（登入時發的 Key 沒有白名單）；
  - 也可以登出後重新登入。
- **提示「額度不足或呼叫太頻繁」**：在設定頁查看剩餘額度；額度用完要到巡瞳續約或購買加值包。批次標註本身已經控制了速度。
- **模型清單中沒有某個專用模型**：表示帳號沒有開通，請到巡瞳 AI 開通對應的方案。
- **辨識出的類別名稱和專案中的不一樣**：專用模型會用它自己的類別名稱，專案中沒有的會自動新建。想統一名稱，可以用「依專案類別辨識」，或辨識後在類別編輯中把名稱改掉。
- **巡瞳私有化部署**：在設定的「進階」中填寫你們自己的平台位址和 API Key。

| H | 隱藏 / 顯示類別名稱 |

**畫多邊形時**：按一下加點，按兩下或 Enter 閉合，退格鍵刪除上一個點。

**點關鍵點時**：按一下為可見，Shift+按一下為被遮擋，N 略過，退格鍵回到上一個點，Esc 或 Enter 結束。

**SAM 選取時**：按一下選取，Shift+按一下排除，退格鍵刪除最後一個點，Enter 採用，Esc 放棄。

**分類專案**：Del 清除類別。
