# 打包发布

两种方式，结果一样：

- **自己电脑打包**：只能打本机系统的包（Windows 电脑打 .exe，Mac 打 .dmg）。
- **GitHub 自动打包**：一次打出 Windows 和 Mac 两个包，不需要 Mac 电脑。

发布新版前，先把三个地方的版本号改成一样：`apps/desktop/package.json`、`apps/desktop/src-tauri/tauri.conf.json`、`apps/desktop/src-tauri/Cargo.toml`。

## 一、自己电脑打包（Windows）

需要：Node.js 20+、Rust（stable）、Visual Studio 生成工具（C++）。开发时能 `npm run tauri dev` 就够了。

在 Git Bash 里：

```bash
cd 仓库目录
git pull
cd apps/desktop
npm install
export WULABEL_FEEDBACK_SECRET='反馈服务的密钥'
npm run tauri build
```

- `WULABEL_FEEDBACK_SECRET` 和反馈服务端 `.env` 里的 `APP_SECRET` 一样。不设也能打包，只是软件里的「意见反馈」发不出去。
- 第一次打包要编译全部依赖，十几分钟；之后几分钟。
- 打好的安装包：`apps/desktop/src-tauri/target/release/bundle/nsis/Wulabel_<版本>_x64-setup.exe`

PowerShell 里设密钥的写法是 `$env:WULABEL_FEEDBACK_SECRET = "反馈服务的密钥"`。

## 二、Mac 电脑打包

需要：Xcode 命令行工具（`xcode-select --install`）、Node.js、Rust。

```bash
rustup target add aarch64-apple-darwin x86_64-apple-darwin
cd apps/desktop
npm install
export WULABEL_FEEDBACK_SECRET='反馈服务的密钥'
npm run tauri build -- --target universal-apple-darwin
```

打好的包：`apps/desktop/src-tauri/target/universal-apple-darwin/release/bundle/dmg/Wulabel_<版本>_universal.dmg`，Apple 芯片和 Intel 的 Mac 都能装，最低 macOS 11。

## 三、GitHub 自动打包（推荐，Windows + Mac 一起）

第一次用要先设一次密钥：GitHub 仓库 → Settings → Environments，建一个叫 `WULABEL_FEEDBACK_SECRET` 的环境，在里面 Add environment secret，名字也填 `WULABEL_FEEDBACK_SECRET`，值填反馈服务的密钥。

之后每次发版，任选一种触发：

- 推一个标签：`git tag v0.2.0 && git push origin v0.2.0`
- 或者在 GitHub 仓库的 Actions 页面选 release → Run workflow

大约 20 分钟后，Releases 页面会多一个**草稿**，里面有 `.exe` 和 `.dmg`。检查没问题，点 Edit → Publish release 才会公开。配置在 `.github/workflows/release.yml`。

## 四、Mac 版第一次打开

软件没有花钱买苹果开发者证书签名，Mac 第一次打开会提示「无法验证开发者」，这是正常的：

- 在「应用程序」里**右键** Wulabel → 打开 → 再点「打开」；
- macOS 15 以后：先双击一次，再到「系统设置 → 隐私与安全性」最下面点「仍要打开」；
- 如果提示「已损坏」，在终端执行 `xattr -cr /Applications/Wulabel.app` 再打开。

只需要第一次这样做。

## 五、发布到官网、GitHub、Gitee

1. 官网：安装包放进网站目录的 `download/`，改首页下载按钮的文件名和版本号；`website/build-guide.ps1` 里的 `$newH2`、`$newH3` 清空（去掉「下一版」标签），重新生成 `guide.html`。
2. GitHub：Releases 里发布（自动打包的话就是把草稿点发布）。
3. Gitee：仓库 → 发行版 → 创建发行版，标签填同一个版本号，附上安装包或官网下载地址。
4. README：把「下载」一节的版本号和文件名换成新版本。
