## 1. 安装与第一次启动

### 1.1 下载安装

1. 打开官网 <https://wulabel.xiaowuiot.com>，点右上角**下载**，或者到 GitHub 的 Release 页下载。
2. 下载 Windows 安装包 `Wulabel_版本号_x64-setup.exe`，双击按提示安装。
3. 安装完从开始菜单或桌面打开 **Wulabel**。

- 系统要求：Windows 10 / 11（64 位）。
- 第一次打开如果提示缺少 WebView2，按提示安装即可（大多数 Win10 / 11 已经自带）。

### 1.2 认识主界面

打开后先看到**项目**页。打开一个项目后，左侧是导航栏，从上到下是：

| 页面 | 做什么 |
|---|---|
| 项目 | 新建、打开、切换项目 |
| 数据 | 导入图片 / 视频 / 数据集，管理图片，导出数据集 |
| 标注 | 画框、画轮廓、选类别、点关键点，AI 辅助和预标注 |
| 体检 | 找出漏标、错标、重复图片等问题 |
| 训练 | 选模型、调参数、开始训练，看训练记录 |
| 评估 | 看指标、混淆矩阵、错例，推荐阈值，误报测试，导出报告 |
| 部署 | 实时验证、导出模型、生成推理服务包、导入现场回流 |
| 协作 | 实时多人协作：开启共享（局域网 / 在线）、成员、分配任务、进度统计 |
| 设置 | 安装训练环境、下载源、巡瞳 AI |

右上角有**反馈**按钮和**关闭项目**。

**【截图 1-1】** 打开一个项目后的主界面全貌：左侧导航栏、右上角的「反馈」「关闭项目」。

## 2. 设置：训练环境、下载源、巡瞳 AI

只做标注、导入导出，不训练的话，这一章可以先跳过。

### 2.1 一键安装训练环境

1. 点左侧**设置**。
2. 看「训练环境」一栏：
   - **显卡**一行显示检测到的显卡、显存、驱动和支持的 CUDA 版本。没有 NVIDIA 显卡会提示「只能用 CPU 训练（会慢很多）」。
   - **PyTorch 版本**下拉框会自动选好推荐的版本（带「推荐」字样），一般不用改：
     - CUDA 12.8：RTX 50 系列等新显卡；
     - CUDA 13.0：需要较新的驱动；
     - CUDA 11.8：较老的显卡和驱动；
     - CPU 版：没有 NVIDIA 显卡。
3. （可选）**安装位置**：默认装在 C 盘的本机数据目录。C 盘空间紧张就点选择，换到空间大的盘，再点**保存**。
4. 点**一键安装**。GPU 版大约 3GB，会自动下载 uv、Python 3.11、PyTorch，进度条下面显示剩余时间。只需要装一次。
5. 装好后状态变成**就绪**，下面显示「显卡可用（cuda）」。

**【截图 2-1】** 设置页「训练环境」：显卡信息、PyTorch 版本下拉框、「一键安装」按钮。

**【截图 2-2】** 安装完成后的状态：绿色「就绪」、显卡可用。

> 训练环境是独立的，不会影响系统里其它 Python。

### 2.2 下载源

1. 在「下载源」一栏点**测速并推荐**。软件会从官方源和国内镜像各下几 MB 测速，自动选上更快的那个。
2. 选「国内镜像」时，SAM、文本提示这些辅助模型也会从国内镜像（hf-mirror.com）下载。

**【截图 2-3】** 下载源测速结果：两个源的速度、自动勾选的那个标「更快」。

### 2.3 巡瞳 AI（可选）

想用巡瞳 AI 平台的模型自动标注、上传模型、拉告警图片，或者用「巡瞳官方中转」在线协作时才需要：

1. 在「巡瞳 AI」一栏点**登录巡瞳 AI 账号**。
2. 浏览器会打开巡瞳 AI 的网页：没登录就先登录（和平时登录巡瞳一样），然后核对网页上的确认码和 Wulabel 里显示的一样，点**允许**。
3. 回到 Wulabel，几秒后自动显示**已登录**、账号名、套餐和剩余额度，以及可用的识别方式（按项目类别识别、平台上开通的专用模型、大模型通用识别）。不用复制粘贴 Key。
4. 浏览器没自动打开时，点**重新打开**，或者复制弹窗里的地址自己打开。
5. **退出登录**：这台电脑上的 Key 会删除，登录时自动创建的 Key 也会在平台上吊销。

已经有 API Key、或者巡瞳是私有化部署的，点**高级：手动填 API Key、私有化部署的平台地址**，填好后点**保存并测试连接**。连接状态会一直显示在这一栏里。

**【截图 2-4】** 巡瞳 AI 已登录：账号名、额度、可用的识别方式。
### 2.4 使用已有的 Python 环境（高级）

已经有装好 PyTorch 的 Python 环境，可以不再下载：

1. 展开「使用已有的 Python 环境（高级）」。
2. 点**选择 python.exe**，选环境里的 `python.exe`（例如 `D:\envs\torch\Scripts\python.exe`）。
3. 点**保存**。这个环境需要有 torch、torchvision、numpy、pillow；导出 ONNX 还需要 onnx。
4. 想改回软件自己的环境：清空路径再保存。

## 3. 新建和打开项目

**一个项目就是一个文件夹**：图片（复制进来的）、标注、模型、训练记录都在里面，整个文件夹拷到另一台电脑也能直接打开。

### 3.1 新建项目

1. 在**项目**页点**新建项目**。
2. **项目名**：例如「工地安全帽检测」。
3. **存放位置**：点**浏览**选一个文件夹，项目会建在这个文件夹下面。
4. **任务类型**（创建后不能修改）：

   | 任务 | 标注方式 | 适合 |
   |---|---|---|
   | 目标检测 | 矩形框 | 找出安全帽、车辆、烟火的位置 |
   | 实例分割 | 多边形轮廓 | 需要精确形状：积水范围、垃圾堆、缺陷区域 |
   | 图像分类 | 整张图一个类别 | 画面「正常 / 异常」、场景归类 |
   | 关键点 | 目标框 + 按模板逐个点 | 人体姿态（跌倒、攀爬）、物体关键部位 |

5. 点**创建**，提示「项目『…』已创建」并自动打开。

**【截图 3-1】** 新建项目对话框：填好项目名、存放位置，任务类型选「目标检测」。

### 3.2 打开项目

- **最近项目**列表里点一下就打开；列表显示每个项目上次打开的时间。
- 不在列表里的，点**打开项目…**，选项目文件夹。
- 项目文件夹被移走或删除后，列表里会提示「找不到文件夹」，可以点「从列表移除」（不会删除文件）。

**【截图 3-2】** 项目页：最近项目列表、「新建项目」「打开项目…」按钮。

## 4. 导入数据

点左侧**数据**。

### 4.1 导入图片或文件夹

1. 先在页面顶部选导入方式：
   - **复制到项目**：图片拷进项目文件夹，项目可以整体拷走（推荐）；
   - **只引用原路径**：只记录图片原来的位置，不占额外空间，但原图不能移动。
2. 导入：
   - 点**导入文件夹**，选一个文件夹（会自动找子文件夹里的图片）；
   - 或者点**更多导入 → 导入图片文件**，选几张图片；
   - 或者直接把图片、文件夹**拖进窗口**，看到「松开鼠标导入图片」时松手。
3. 导入时会显示进度「已处理 N / M 张（计算指纹、生成缩略图）」。完成后提示新增几张、跳过几张重复的。

导入时自动**按内容去重**（同一张图不会导入两次），并按照片的 EXIF 信息**摆正方向**。

**【截图 4-1】** 数据页全貌：顶部「复制到项目 / 只引用原路径」、「导入文件夹」「更多导入」「导出数据集」「管理」按钮，下面的标注进度和图片网格。

### 4.2 导入视频（抽帧）

1. 点**更多导入 → 导入视频（抽帧）**，选一个或多个视频文件。
2. 在「视频抽帧」对话框里设置：
   - **每隔 N 秒抽 1 帧**：目标变化慢就隔久一点，避免一堆几乎一样的图；
   - **每个视频最多 N 帧**（0 = 不限）。
3. 点**开始抽帧**。第一次使用会自动下载 ffmpeg（约 90MB），之后不用再下。
4. 抽出的帧复制进项目，按内容自动去重。完成后提示「从 N 个视频抽出 M 帧：新增 K 张」。

**【截图 4-2】** 视频抽帧对话框：每隔几秒、最多几帧。

### 4.3 从视频流抽帧（RTSP / 直播 / 回放）

1. 点**更多导入 → 从视频流抽帧（RTSP / 直播 / 回放）**。
2. 填地址：RTSP 摄像头（`rtsp://…`），或 http(s) 的直播、回放、点播地址（mp4、m3u8、flv）。
   - 海康：`rtsp://用户名:密码@IP:554/Streaming/Channels/101`（主码流）或 `102`（子码流）
   - 大华：`rtsp://用户名:密码@IP:554/cam/realmonitor?channel=1&subtype=0`
3. 点**测试连接**，会显示分辨率，以及是「直播流（无限，需设上限）」还是「回放流 · 时长 …」。
4. 设置：
   - **每隔 N 秒抽 1 帧**；
   - **最多抽 N 帧**、**最长采集 N 分钟**（0 = 不限，仅直播）。**直播是无限流，至少要设其中一个**；
   - 勾选**跳过几乎相同的帧**：画面静止时少存重复图。
5. 点**开始采集**。图片边采边入库，在数据页就能看到一张张出现。
6. 采集中可以点**最小化**继续干别的，右下角会显示「采集中 · 已抽 N 帧」，点**展开**回来；点**停止采集**随时结束，已采的图会保留。
7. 采集的图存在项目的 `images/stream_地址_时间/` 文件夹里，完成后可以点**打开文件夹**查看。

**【截图 4-3】** 从视频流抽帧对话框：填好地址、测试连接后显示分辨率和「直播流」，下面的上限设置。

**【截图 4-4】** 采集过程中：数据页里新图陆续出现，进度显示「已采集 N 帧 · 已入库 M 张」。

> 账号密码只在采集时使用，软件不会把带密码的地址写进项目文件夹的名字里。

### 4.4 导入带标注的数据集

已经有别处标好的数据，可以连标注一起导入：

1. 点**更多导入**，按项目类型选：
   - 检测 / 分割项目：**导入带标注的数据集（YOLO / COCO / VOC）**，支持 YOLO（含 seg）、COCO（含分割）、VOC；
   - 关键点项目：**导入带标注的数据集（YOLO-pose / COCO 关键点）**；
   - 分类项目：**导入分类数据集（每个类别一个文件夹）**，选的文件夹下面每个子文件夹是一个类别（也可以再分 train / val 一层）。
2. 选数据集的根文件夹，软件自动识别格式。
3. 完成后提示「已导入 YOLO 数据集」等，以及新增了哪些类别。

### 4.5 撤销、删除、清空

都在**管理**菜单里：

- **撤销上次导入（N 张）**：刚导错了，一键删掉上次导入的图（视频流的一次采集算一次导入）。
- **选择图片删除**：进入选择模式，点图片勾选（可以「全选本页」），再点删除，最后点**完成**退出。
- **清空全部图片**：删除项目里所有图片。

删除时图片的标注一起删除，无法恢复；复制进项目的图片副本会被删掉，你电脑上的原图不受影响。

### 4.6 图片质量筛查

模糊、太暗、过曝的图标起来费劲，训练时也容易把模型带偏，可以先筛掉：

1. 点**管理 → 图片质量筛查（模糊、过暗、过曝）**。
2. 默认勾选**只看未标注的图**；想检查全部就取消勾选。
3. 点**开始筛查**。
4. 结果按问题分类：**模糊**、**过暗**、**过曝**、**对比度低**，点上面的标签筛选。每张图下面有清晰度、亮度、过曝比例、对比度的数值。
5. 处理：
   - **逐张去看**：跳到标注页一张张看，自己决定；
   - **设为跳过**：标成「跳过」，不参与训练（图还在，以后能撤回）；
   - **删除**：直接删掉。

**【截图 4-5】** 图片质量筛查结果：问题分类标签、缩略图和数值、底部三个按钮。

### 4.7 从巡瞳 AI 拉取告警图片

模型部署到巡瞳 AI 平台后，现场的告警截图（尤其是误报、漏报）正是最值得补的数据：

1. 先在**设置**里配好巡瞳 AI（见 2.3）。
2. 在**数据**页点**更多导入 → 从巡瞳 AI 拉取告警图片**。
3. 选时间范围（最近 1 / 3 / 7 天；平台的告警图片保留 7 天，记得定期拉）、模型（全部或某一个）、**最多 N 张**。只有配置了推送通道的巡瞳账号才会产生告警记录。
4. 默认勾选**平台识别出的框作为预标注**：按类别名对应项目里的类别，没有的会新建。
5. 点**开始拉取**。图片存在项目的 `images/xuntong_时间/` 文件夹，识别框显示为虚线（来源「巡瞳」）。
6. 到标注页检查：误报的框删掉（没有目标的图直接**通过**，作为负样本），漏的补上，然后重新训练。

**【截图 4-6】** 从巡瞳 AI 拉取告警图片的对话框。

## 5. 标注

点左侧**标注**。

### 5.1 认识标注页

- **顶部**：左右箭头翻图、当前图名和序号（第几张 / 共几张）、分辨率、状态标签（未标注 / 已标注 / 已审核 / 已跳过）；筛选按钮**全部 / 未标注 / 已标注 / 已审核**；最右边是缩放比例和保存状态（已保存 / 未保存 / 保存中… / 保存失败）。
- **左侧工具栏**：选择、画框（或画轮廓）、SAM 智能选取、撤销、重做、复制上一张、关键帧插值、往后跟踪、适应窗口。鼠标悬停会显示说明和快捷键。
- **中间**：图片画布。滚轮缩放，按住空格或右键拖动画面。
- **右侧**：「AI 辅助」、「类别」、「本图对象」（分类项目是「本图类别」）、「审核」几块。
- **画布下方**：当前项目可用的快捷键提示。
- **最底部**：前后几张图的缩略图条，点一下直接跳过去。

改动会**自动保存**，不用手动保存。

**【截图 5-1】** 检测项目的标注页全貌，标出顶部、左侧工具栏、画布、右侧面板四个区域。

### 5.2 添加和管理类别

1. 在右侧「类别」里的输入框填「新类别名，回车添加」，比如「安全帽」，按回车。
2. 前 9 个类别可以用数字键 **1–9** 快速切换，当前类别高亮。
3. 点类别旁边的编辑按钮可以：
   - 改名字、改颜色；
   - 填**英文提示词**（给「文本提示」自动标注用，可以写多个，用逗号隔开，例如 `helmet, hard hat`）；
   - 填**识别说明**（给巡瞳 AI「按项目类别识别」用：这个类别具体指什么、什么情况算 / 不算，比如「头上没有安全帽的人；戴了帽子但没系带也算」）；
   - 删除类别（这个类别的标注会一起删除）。

**【截图 5-2】** 右侧类别列表，以及「编辑类别」对话框（名字、颜色、英文提示词）。

### 5.3 目标检测：画框

1. 按 **1–9** 选类别。
2. 按 **R**（或点左侧画框工具），在目标上**按住鼠标拖出一个框**。
3. 调整：按 **V** 切到选择工具，点中框后可以拖动位置、拉边角改大小。
4. 删除：选中框按 **Del** 或 **退格**；按 **Esc** 取消选中。
5. 改类别：选中框后按数字键，或在右侧「本图对象」里改。
6. 按 **H** 隐藏 / 显示框上的类别名，框很密时方便看。

**【截图 5-3】** 画框过程：一张图上已经画好几个不同类别的框，其中一个处于选中状态（显示调整手柄）。

### 5.4 实例分割：画轮廓

1. 选类别，按 **R**。
2. 沿目标边缘**一个点一个点地点击**。
3. **双击**或按 **Enter** 闭合轮廓；点错了按 **退格** 撤掉上一个点。
4. 选中轮廓后可以拖动顶点微调。
5. 更快的办法是按 **S** 用 SAM 智能选取，点一下自动出轮廓（见第 6 章）。

**【截图 5-4】** 分割项目里画好的多边形轮廓，选中后显示顶点。

### 5.5 图像分类：一键一张

1. 看图，按数字键 **1–9** 选类别。画面左上角显示当前类别。
2. 打开右侧的**选完下一张**开关后，按完数字键自动跳到下一张，一键一张。
3. 按 **Del** 清除这张的类别；按 **Ctrl+D** 沿用上一张的类别。

**【截图 5-5】** 分类项目的标注页：左上角显示当前类别，右侧「选完下一张」开关。

### 5.6 关键点

1. 先看右侧的**关键点模板**。默认是「COCO 人体 17 点」（鼻子、左眼、右眼……左踝、右踝）。要改就点**编辑**：
   - **模板名**；
   - **点名**（每行一个，点的顺序就是标注时点击的顺序）；
   - **连线**（每行一对序号，如 `1-2`，用来画骨架）；
   - 也可以点**使用 COCO 人体 17 点**恢复默认。
   - 已经有关键点标注后，只能改名字和连线，不能增减点数。
2. 选类别，按 **R** 画出目标框。
3. 画完框后按提示**依次点每个关键点**（画面下方提示当前要点的是哪个点，比如「点击 左肩（6/17）」）：
   - 普通点击：可见的点；
   - **Shift + 点击**：被遮挡的点；
   - **N**：跳过看不到的点；
   - **退格**：回到上一个点；
   - **Esc**：结束这个目标。
4. 微调：选中目标后可以直接拖动关键点。右侧列出每个点的状态，点名字可以单独重新放这个点；点状态可以在「可见 / 被遮挡」之间切换。
5. 选中目标后点**重放关键点**，可以从第一个点开始重新标。

**【截图 5-7】** 右侧关键点列表（每个点的名字和可见 / 被遮挡状态），以及「编辑关键点模板」对话框。

### 5.7 复制上一张、撤销重做

- **Ctrl+D**（或左侧复制按钮）：把上一张的标注整套搬过来，场景相似、连续帧时很省事。分类项目是沿用上一张的类别。
- **Ctrl+Z** 撤销、**Ctrl+Y** 重做。

### 5.8 审核、跳过

右侧「审核」一块：

- **通过并下一张**（快捷键 **Enter**）：标成「已审核」，跳到下一张。
- **跳过**：标成「已跳过」，这张不参与训练。适合模糊、无关的图。
- **撤回**：改回「已标注」或「未标注」。

顶部的筛选按钮可以只看「未标注」的图，标完一张少一张。

### 5.9 视频帧：关键帧插值、往后跟踪

适用于检测和关键点项目。视频抽出来的帧（同一个文件夹里，按文件名排好顺序）可以不用一帧帧画。

**关键帧插值**（目标匀速移动的片段）：

1. 翻到片段开头的一帧，把目标都标好（这就是一个「关键帧」）。
2. 翻到片段结尾的一帧，也把同样的目标标好。
3. 在结尾这帧点左侧的**关键帧插值**按钮。
4. 软件按类别和位置把两头的目标一一对应，把中间的帧自动补上。提示「已在中间 N 帧上插值 M 个目标」；两头对不上的目标会单独说明。

**往后跟踪**（目标移动不规则时）：

1. 在当前帧把目标标好。
2. 点左侧的**往后跟踪**按钮，在弹出的小窗里填**帧数**（默认 30，最多 500），点**跟踪**。
3. 软件从这一帧的框出发逐帧跟下去。目标被挡住或跟丢了就停；碰到后面手动标过的帧也停，不会覆盖人工标注。
4. 跟完自动跳到最后跟到的那一帧。框偏了就拖正（拖过的框就变成手动标注，这一帧成了新的关键帧），再点**往后跟踪**接着跟。

插值和跟踪出来的框，在右侧「本图对象」里来源显示为「插值」「跟踪」。重新插值或跟踪会替换它们，手动标的框不会被改动。

**【截图 5-8】** 左侧工具栏的「关键帧插值」「往后跟踪」两个按钮，以及往后跟踪弹出的小窗（帧数、跟踪按钮）。

**【截图 5-9】** 跟踪完成后的效果：连续几帧的缩略图里，框跟着目标移动。

> 省力思路：先手标一小批（几十到一两百张），训一个初版模型，再用它预标注剩下的图（第 12 章），你只要改错。

## 6. AI 辅助标注

还没有自己的模型时，也可以让 AI 帮你标。

### 6.1 SAM 智能选取

1. 选类别，按 **S**（或点左侧 SAM 按钮）。
2. 第一次使用要安装组件、下载模型，可能需要几分钟，画面上显示「SAM 准备中…」。有 NVIDIA 显卡用 SAM ViT-B，否则用小巧的 SlimSAM。
3. 在目标上**点一下**，自动选出目标的轮廓（预览）。
   - 选多了：**Shift + 点击**多出来的地方排除；
   - 选少了：再点没选上的部分；
   - 点错了按 **退格** 撤掉最后一个点；
   - 也可以**拖一个框**把目标框住。
4. 满意后按 **Enter** 采用为当前类别；按 **Esc** 放弃。
5. 结果：分割项目得到多边形，检测项目得到贴边的框，关键点项目得到一个新目标（再点「重放关键点」标点）。

**【截图 6-1】** SAM 选取中：点了一下后高亮出目标轮廓，画面下方提示「已选出目标 · Enter 采用为『…』」。

### 6.2 文本提示

按类别名自动在图里找目标：

1. 在右侧「AI 辅助」里选**文本提示**。
2. 模型只懂英文。中文类别名要在类别的编辑里填**英文提示词**（如 安全帽 → helmet）；常用类别名已经内置了对照。
3. 调**置信度**：找得太多就调高，找不到就调低。
4. 点**标注本图 (P)** 标当前这张，或点**批量预标注**一次标一批。
5. 第一次使用要下载模型，需要几分钟。分割项目会再用 SAM 出轮廓。

**【截图 6-2】** 右侧「AI 辅助」选「文本提示」：置信度滑块、「标注本图 (P)」「批量预标注」按钮，画面里出现虚线框。

### 6.3 巡瞳 AI

（巡瞳 AI 的完整用法见第 16 章。）

1. 先在**设置**里配好巡瞳 AI（见 2.3）。
2. 在「AI 辅助」里选**巡瞳 AI**，在「选择识别模型」里选：
   - **按项目类别识别（推荐）**：只找项目里的类别，类别名原样对上，按每个类别的识别说明和整体规则来，不会多认出你不需要的东西；
   - 平台上开通的**专用模型**；
   - **大模型通用识别**：按安全隐患类别（消防、电气、环境卫生等）找。
3. 点**标注本图 (P)** 或**批量预标注**。用专用模型（比如垃圾分类）批量预标注很快：每次 8 张一批、两批同时发；大模型和按项目类别识别是一张一张来的，慢一些。
4. 巡瞳 AI 每张图计 1 次调用，会消耗你账号的套餐额度；批量前会提示。

### 6.4 识别规则：和 AI 说怎么识别

光有类别名，AI 不一定知道你要的到底是什么。可以把规则写清楚，或者直接和 AI 聊：

1. 在「AI 辅助」标题旁点**识别规则**，右侧打开识别规则面板。
2. **和 AI 聊**：用大白话说要怎么识别，比如「戴了帽子但没系带也算未戴安全帽」「反光衣不算」「只看画面下半部分的通道」，也可以问「这张图左边那个人为什么没认出来」。
   - 默认勾选**附上当前这张图**，AI 会按新规则在这张图上试识别。
   - AI 回答后，如果它建议更新规则，会显示「AI 建议更新规则」和具体内容，点**采用这些规则**才会保存。
   - 试识别有结果时，点**把试识别的 N 个框加到这张图**，直接用作预标注。
   - `Ctrl+Enter` 发送。每次对话会用巡瞳 AI 的额度。
3. **当前规则**：可以直接改**整体规则**（对所有类别都适用）和**每个类别的识别说明**，点**保存规则**。
4. 之后用巡瞳 AI 的「按项目类别识别」预标注，就按这些规则来。
5. （可选）在「当前规则」最下面点**同步到巡瞳平台**：把类别和规则存到巡瞳平台上。默认**不启用**，不影响平台现在的识别。绑定后，以后每次保存或采用规则会自动同步内容（不会改你在巡瞳控制台里设的启停和适用场景）。
6. 想让巡瞳平台自己的识别（抓拍助手、告警推送）也只报你要的类别，打开**平台识别也用这套规则**。注意：打开后整个巡瞳账号的识别都按这个项目的类别来，适用场景可以在巡瞳控制台的「识别规则」里调。不想同步了点**解除绑定**（平台上的规则不会删）。每个巡瞳账号最多 20 套识别规则。

限制：按项目类别识别最多 30 个类别，类别名不超过 30 个字；整体规则最多 1000 字，每个类别的识别说明最多 500 字。

协作时，成员也能打开识别规则和 AI 聊（发起人开放了 AI 辅助的话，用的是发起人的额度）；能不能改规则跟着「成员可以新增、修改类别」开关走。

**【截图 6-3】** 识别规则面板：和 AI 的对话、AI 建议的规则和「采用这些规则」按钮。

### 6.5 检查辅助结果

AI 标出来的框、轮廓显示为**虚线**。检查一遍：错的删掉，偏的拖正，漏的补上，然后按 **Enter** 通过。

## 7. 数据体检

点左侧**体检**，一键找出数据里的问题。

1. 选检查方式：
   - 有训练好的模型：选「用模型检查：模型名 · mAP50 …」，规则和模型一起查；
   - 没有模型：选「只做规则检查（不用模型）」。
2. 点**开始体检**。
3. 结果按问题分类显示：

   | 问题 | 意思 | 需要模型 |
   |---|---|---|
   | 疑似漏标 | 模型很确定这里有目标，但没有标注 | 是 |
   | 疑似类别错 | 框的位置对上了，但类别和模型判断的不一样 | 是 |
   | 框不准 | 类别一致，但框和模型预测的重合度低 | 是 |
   | 疑似多余框 | 标了框，但模型在这个位置什么都没看到 | 是 |
   | 极小框 | 短边小于 8 像素，模型几乎学不到 | 否 |
   | 重复框 | 同一张图同类别的两个框几乎完全重叠 | 否 |
   | 重复图片 | 画面几乎一样的图片，会让评估结果虚高 | 否 |
   | 无类别 | 框没有类别，不会参与训练 | 否 |

4. 每条问题可以：
   - **去修改**：跳到标注页，高亮这个框；
   - **加为标注**：疑似漏标时，直接按模型的判断加一个框；
   - **不是问题**：忽略，以后体检不再提示。
5. 重复图片按组显示，可以每组**保留**一张，删除其余的。
6. 页面下方还有**类别分布**（框数 · 图片数）和**框大小分布**，类别太少、框太小时会给出建议。

**【截图 7-1】** 体检结果：问题分类和数量、几条问题的缩略图和「去修改」「加为标注」「不是问题」按钮。

## 8. 数据集版本

把某一时刻的数据存成快照，方便对比和回退。

1. 在**数据**页点**管理 → 数据集版本（保存快照、对比、恢复）**。
2. 填**版本名**（如 v1、补充夜间图）和**备注**（可选），点**保存当前数据为新版本**。
   - 版本里存的是当前已标注、已审核的图和标注，以及训练 / 验证 / 测试划分。
3. 版本列表里每一行可以：
   - **和当前数据对比**：看新增的图、移出的图、标注改过的图，以及各类别标注数量的变化；
   - **导出这个版本**；
   - **恢复到这个版本**：恢复前会自动把当前数据存成「恢复前自动备份」版本，随时能恢复回来；
   - **改名、备注**、**删除这个版本**（只删快照，不影响当前数据和已训练的模型）。
4. 在**训练**页的「训练数据」里可以选某个版本来训练（见 10.1）。

## 9. 多人协作

图多、一个人标不完时，有两种方式：

- **实时协作**：几个人同时标同一个项目。你的电脑当主机，成员用浏览器打开地址、登录后就能标，改动实时同步。局域网和外网都可以。
- **离线分包**：没有网络、或者数据不能出公司时，把图分成标注包拷给别人，标完合并回来（见 9.10）。

### 9.1 开启实时协作

1. 点左侧**协作**。
2. 先在「成员」里添加成员：填**名字**（登录用），选**角色**，密码默认随机生成（可以改），点**添加**。弹出的账号密码复制下来发给他（只显示这一次，忘了可以**重设密码**）。
   - **标注员**：只能看到、修改分给自己的图；
   - **审核员**：能看全部图，负责审核通过或打回；
   - 你自己是**管理员**。
3. 在「共享」里选共享方式：
   - **局域网**：成员和你在同一个公司网络、同一个 Wi-Fi，速度最快，数据不出公司。
   - **在线 · 自建中转**：成员在外网（外包、在家办公）。需要一台你们自己的云服务器装上 Wulabel 中转服务（仓库 `relay/` 文件夹有部署说明），填**中转地址**和**密钥**。数据只经过你们自己的服务器。
   - **在线 · 巡瞳官方中转**：成员在外网、又没有自己的服务器时用。用你的巡瞳 API Key 连巡瞳的中转服务器。图片和标注会经过巡瞳服务器转发（只转发、不保存），数据敏感的项目请用前两种。
4. 填**你的名字**（成员看到的发起人名字）。**端口**一般不用改（默认 8765）。
5. 选项：
   - **成员可以用 AI 辅助**：SAM 智能选取、模型预标注、文本提示，都在你的电脑上算；和 AI 聊识别规则会用你的巡瞳额度。
   - **成员可以新增、修改类别和识别说明**：删除类别会删掉它的全部标注，只有你能做。
   - **成员的画面叠加带他名字的水印**：防截图外传，适合外包。
6. 点**开启协作**。页面会显示**局域网地址**（如 `http://192.168.1.20:8765/`）；在线模式还会显示**外网地址**（如 `https://relay.example.com/s/xxxxxxxxxxxx/`）。把地址和各自的账号密码发给成员。
   - 第一次开启时 Windows 可能弹出防火墙提示，点**允许**。
   - 开着协作时，三个选项可以随时改，马上生效。
   - 点**停止协作**，成员马上断开，已经保存的标注不受影响。换项目、关掉 Wulabel 也会停止。

**【截图 9-1】** 协作页：共享方式、选项、成员列表和添加成员。

**【截图 9-2】** 开启后：局域网地址、外网地址、在线人数。

### 9.2 分配任务

1. 在「分配任务」里选标注员（可以点**选全部标注员**）。
2. 选范围：
   - **还没分给人的未标注图**（最常用）；
   - **全部未标注图**（已分配的也重新分）；
   - **未审核的图**（未标注 + 已标注）。
3. **每人 N 张**：不填就把范围内的图平均分完。按图片顺序连续分，视频的连续帧分给同一个人。
4. 点**分配**。成员那边会自动刷新出新任务。
5. 成员列表里能看到每个人分配了几张、交了几张、被打回几张。点**收回任务**把他还没交的图收回，可以再分给别人。

### 9.3 成员怎么标（浏览器）

1. 用 Chrome 或 Edge 打开发起人给的地址，填**名字**和**密码**登录。自己的电脑可以勾**记住登录**。不用装软件。
2. 进来就是标注页，只显示分给自己的图。操作和 Wulabel 里一样：画框、快捷键、AI 辅助（发起人开放了的话）。右上角显示今天提交了几张。
3. 标完点**提交并下一张**（`Enter`），等审核。
4. 被打回的图在筛选的**被打回**里，图上方显示打回原因，改好再提交。
5. 别人正在标的图会提示「某某正在标这张图」，只能看，他的改动实时显示；他离开后自动变成可以编辑。
6. 网络断了右上角会提示「实时连接断开，正在重连」，恢复后自动继续，已经保存的不会丢。

### 9.4 审核

1. 审核员（或你自己）在标注页筛选**已标注**，逐张看。
2. 没问题：点**通过并下一张**（`Enter`）。
3. 有问题：点**打回**，勾选常见原因（漏标、框不准、类别标错、多标了、关键点不对），或者写清楚哪里要改，点**打回**。
4. 打回的图回到原标注员的「被打回」里，他改好再提交。

### 9.6 三种共享方式怎么选

| | 局域网 | 在线 · 自建中转 | 在线 · 巡瞳官方中转 |
|---|---|---|---|
| 适合 | 同一个公司网络、同一个 Wi-Fi | 外包、在家办公，有自己的云服务器 | 外包、在家办公，没有服务器 |
| 成员访问的地址 | `http://你电脑的IP:8765/` | `https://你的中转/s/编号/` | `https://xuntongai.com/wulabel-relay/s/编号/` |
| 速度 | 最快 | 取决于服务器带宽 | 取决于巡瞳服务器带宽 |
| 数据经过 | 只在公司内网 | 你们自己的服务器（只转发、不保存） | 巡瞳的服务器（只转发、不保存） |
| 需要准备 | 不用 | 一台云服务器，按 `relay/README.md` 装中转服务 | 巡瞳 AI 账号（设置里登录） |

- 三种方式下，图片和标注都只存在你的电脑上，中转服务器只负责转发。
- 在线方式的共享编号固定不变：下次开启还是同一个地址，成员收藏一次就行。
- 你的电脑要一直开着、Wulabel 要一直开着协作，成员才能连上；电脑休眠了成员会看到「发起人不在线」。建议在电源设置里关掉自动睡眠。

### 9.8 一个完整的例子

以「外包团队标 2000 张垃圾分类图，自己团队审核」为例：

1. **准备**：在 Wulabel 里新建检测项目，导入 2000 张图，在右侧加好类别（可回收物、厨余垃圾、有害垃圾、其他垃圾）。可以先用巡瞳 AI 的专用模型批量预标注一遍（见 16.4），标注员只需要改错，快很多。
2. **添加成员**：在「协作」页加 3 个标注员（外包的张三、李四、王五）、1 个审核员（自己团队的小陈），把账号密码分别发给他们。
3. **开启协作**：选「在线 · 巡瞳官方中转」（或自建中转），勾上「水印」，开启，把外网地址发给 4 个人。
4. **分配**：选全部标注员，范围「还没分给人的未标注图」，不填每人张数，点分配，每人大约 666 张。
5. **标注**：标注员用浏览器打开地址登录，只看到自己的图，标完一张按 `Enter` 提交。
6. **审核**：小陈筛选「已标注」，逐张检查。没问题按 `Enter` 通过；有问题点「打回」，勾选「漏标」并写上「右下角还有一个瓶子」。打回的图回到原标注员的「被打回」里，改好再提交。
7. **盯进度**：你在「协作」页看谁在线、谁标得快、谁被打回多；某人掉队了，用「收回任务」把他没做的图收回，再分给别人。
8. **结算**：在「进度与工作量」里选时间段，点「导出 CSV」，按提交张数和通过率结算外包费用。
9. **收尾**：全部审核通过后，停止协作，回到 Wulabel 照常训练、评估、部署。

### 9.9 常见问题

- **成员打不开局域网地址**：
  - 确认他和你在同一个网络（连的是同一个公司网络或 Wi-Fi，访客网络通常不通）；
  - 第一次开启时 Windows 防火墙的提示要点「允许」，点了「取消」的话，要到「Windows 安全中心 → 防火墙 → 允许应用通过防火墙」里勾上 Wulabel；
  - 端口被占用时换一个，比如 8766。
- **成员看到「发起人不在线」**：你的 Wulabel 没开协作、电脑睡眠了，或者断网了。重新开启后让他刷新页面。
- **外网地址一直显示「正在连接中转服务器」**：
  - 自建中转：检查地址和密钥是否和部署时一样；
  - 官方中转：确认已经登录巡瞳 AI 账号。
- **成员说「这张图没有分给你」**：标注员只能打开分给自己的图。让管理员把图分给他，或者换一个人标。
- **两个人想同时改同一张图**：做不到，后打开的人是只读。等前一个人翻到下一张就能改。
- **成员断网了，标的会丢吗**：已经保存的不会丢（每次改动都会自动保存到你的电脑）。网络恢复后，页面会自动重连。
- **能用手机标吗**：能打开、能看，但画框还是建议用电脑。
- **最多几个人**：没有硬性限制，十几个人同时标没问题。人多时你的电脑要一直开着、网络稳定。
- **停止协作或关掉 Wulabel 会怎样**：成员马上断开，看到「发起人已经停止了协作」；已经保存的标注都在。下次开启后他们刷新页面就能继续。
- **换了项目**：协作会自动停止。协作是针对当前打开的项目的。
### 9.10 离线分包

没有网络、或者数据不能离开公司时用。每个包是一个独立的 Wulabel 项目，拷给别人标，标完合并回来。

**分包：**

1. 在**数据**页点**管理 → 多人协作（分包、合并回来）**，切到**分包**。
2. **放在**：选一个文件夹，标注包会建在这里。
3. 填**标注人**，每行一个（或用逗号隔开），例如「张三」「李四」。几个人就分几个包。
4. 选范围：**只分未标注的图** / **未审核的**（未标注 + 已标注待复核）/ **全部**（跳过的除外）。
5. 勾选**带上已有的标注**：模型预标注过的图，让标注人在上面改，更快。
6. （可选）勾选**给图片打码**，把人脸、车牌等隐私区域打码后再发出去（见 13.2）。
7. 点**分成 N 个包**。完成后自动打开存放文件夹。把包文件夹拷给对应的人，对方用 Wulabel **打开项目**就能标。

**【截图 9-7】** 多人协作「分包」页。

**合并回来：**

1. 把标完的包文件夹拷回来。
2. 打开**多人协作**，切到**合并回来**（或者在「分出去的包」列表里直接点那个包的**合并**）。
3. 选包文件夹。选项：**冲突时用包里的覆盖**（分包后原项目里也改过的图，默认不覆盖）、**标注人在包里新加的图也导入**。
4. 点**合并**。结果显示合并了几张、几张没变化、新加几张、冲突几张。有冲突时点**逐张去看**。

## 10. 训练

点左侧**训练**。第一次训练前要装好训练环境（见第 2 章），没装时页面会提示**去安装**。

### 10.1 设置训练参数

页面上方显示「可训练图片」数量。还没划分的图，开始训练时会按 8:2 自动分到训练集和验证集。

| 选项 | 说明 |
|---|---|
| 起点 | 默认「从预训练权重开始（从头训）」。补了新数据后可以选「接着『某次训练』继续训」，比从头训快也更稳；类别有变化时，分类部分会重新学。 |
| 模型 | 按项目任务列出，标「推荐」的适合大多数情况，见下表。接着训练时沿用那次的模型。 |
| 训练轮数 | 数据越少需要的轮数越多，一般 20~50。 |
| 输入尺寸 | 目标小（远处的人、安全帽）用大尺寸，速度会变慢。分类一般用 224。 |
| 批大小 | 显存不够报错时调小。 |
| 训练数据 | 「当前数据」或某个数据集版本。 |
| 设备 | 「自动（有显卡用显卡）」或「只用 CPU」。 |
| 只用已审核的图片 | 勾上后只用审核过的图训练。 |

可选的模型：

| 任务 | 模型 | 特点 |
|---|---|---|
| 检测 | Faster R-CNN MobileNetV3 | 速度快、显存占用小，适合入门和没有独立显卡的电脑 |
| 检测 | Faster R-CNN ResNet50 | 精度更高，更慢，建议 6GB 以上显存 |
| 检测 | RetinaNet | 单阶段，精度接近 Faster R-CNN，转 TensorRT 更顺 |
| 检测 | FCOS | 单阶段、无锚框，结构简单，适合部署 |
| 检测 | SSDLite | 单阶段、很轻，适合 CPU 和 NPU 边缘设备；固定 320 输入，小目标一般 |
| 分割 | Mask R-CNN | 实例分割，建议 6GB 以上显存 |
| 关键点 | Keypoint R-CNN | 人体 17 点能用上 COCO 预训练 |
| 分类 | MobileNetV3 / EfficientNet-B0 / ResNet50 | 从轻快到更准 |

### 10.2 数据增强

3. 点**预览效果**，看几张图随机增强后的样子（每张图随机变两次，红框是跟着变换后的标注位置），确认不会太夸张。

### 10.5 导入外部模型

## 12. 模型预标注和挑图

### 12.1 用自己的模型预标注

1. 到**标注**页，在右侧「AI 辅助」里选**我的模型**，下拉框选一个训练好的模型（显示名字和 mAP50 / 准确率）。
2. 调**置信度**。
3. 单张：按 **P** 或点**预测本图 (P)**。
4. 批量：点**批量预标注**，给一批未标注的图都标上。
5. 预标注的框是虚线，检查、改好后按 **Enter** 通过。分类项目会显示「模型的候选」，前 3 个类别点一下就能采用。

标得越多 → 模型越准 → 预标注越省事。

### 13.1 导出

1. 在**数据**页点**导出数据集**。
2. **格式**（按项目任务）：
   - 检测：YOLO、COCO、VOC；

4. 导出时会多一个「打码」阶段的进度。

打码只改导出的副本，项目里的原图不动。自动查找可能漏掉很小、侧脸、远处的目标，重要数据请抽查。

## 14. 部署

点左侧**部署**，选一个训练好的模型。页面有四个标签：**实时验证**、**导出模型**、**推理服务包**、**现场回流**。

### 14.1 实时验证

接上摄像头或视频，现场看模型效果：

1. 选**RTSP 摄像头**或**本地视频**。
2. 填 RTSP 地址（例如 `rtsp://admin:密码@192.168.1.64:554/Streaming/Channels/101`），或点**选择视频文件**。
3. 点**开始**，画面上实时画出检测框，顶部显示分辨率和是显卡还是 CPU 推理。
4. 拖**置信度**滑块调阈值。
5. 看到漏检、误报的画面，点**截图加入数据集**，图会作为「未标注」加入，标注后再训练。
6. 点**停止**结束。

**【截图 14-1】** 实时验证：视频画面上的检测框、置信度滑块、「截图加入数据集」按钮。

### 14.2 导出模型

1. 选格式：
   - **ONNX（动态尺寸）**：通用格式，onnxruntime 在 Windows / Linux / ARM 上都能跑；
   - **ONNX（固定尺寸）**：输入固定为 [1,3,N,N]，给需要固定形状的推理框架用；
   - **OpenVINO**：Intel CPU、核显、工控机加速，软件里直接转换并验证（首次使用会自动安装 OpenVINO）；
   - **TensorRT 转换包**：NVIDIA 显卡、Jetson，需要在目标设备上运行脚本生成引擎；
   - **RKNN 转换包**：瑞芯微 RK3588 / 3568 等，需要在 Ubuntu 上运行脚本转换。
2. 需要固定尺寸时设置尺寸。
3. 选**导出到**的位置、**文件夹名**，点**导出**。每种格式显示成功或失败，点**打开**查看。

内置的 Faster R-CNN 是两阶段模型，NPU（RKNN）和老版本 TensorRT 对它支持有限，转换可能失败或速度不理想；要上这类设备建议训练单阶段模型（RetinaNet、FCOS、SSDLite）。ONNX 和 OpenVINO 可以放心使用。

**【截图 14-2】** 导出模型：格式勾选、导出位置、导出结果（成功 / 失败）。

### 14.3 推理服务包

生成一个拿到现场电脑就能跑的检测服务（目前支持检测模型）：

1. **视频流**：填名称和地址（`rtsp://…` 或视频文件路径），点**添加一路**可以加多路。
2. **检测间隔（秒）**：每路视频每隔多久检测一帧。
3. **告警规则**：
   - **告警类别**（不选表示所有类别都告警）；
   - **置信度阈值**（可以参考评估页的推荐阈值）；
   - **去重间隔（秒）**：同一路视频同一类别，这段时间内只告警一次；
   - **生效时段**：全天，或如 `07:00-19:00`；
   - **保存告警截图（带框）**。
4. **告警推送**：
   - Webhook：告警时 POST JSON 到这个地址，可选**附带截图（base64）**；
   - MQTT：服务器地址、主题、用户名、密码（不填则不推送）。
5. **服务**：**HTTP 接口端口**；**用显卡推理**（现场电脑要装 onnxruntime-gpu，否则自动用 CPU）。
6. **现场回流**：模型拿不准（置信度在设定区间内）的画面存到服务包的 `reflux/` 文件夹。
7. 选**生成到**的位置，点**生成推理服务包**。
8. 把整个文件夹拷到现场电脑：Windows 双击 `run.bat`，Linux 运行 `sh run.sh`。配置在 `config.json`，说明见 `README.md`。现场电脑不需要 PyTorch 和显卡，只依赖 onnxruntime、OpenCV、numpy。

**【截图 14-3】** 推理服务包表单：视频流、告警规则、告警推送、服务设置。

### 14.4 现场回流

1. 服务包在现场运行时，会把模型拿不准的画面存到 `reflux/` 文件夹。
2. 定期把 `reflux/` 拷回来，在**现场回流**标签点**导入现场回流图片**，选这个文件夹。
3. 点**去标注**，筛选「未标注」，用模型预标注后修正。
4. 重新训练，再生成新的服务包，替换现场的 `model.onnx`。模型会越用越准。

### 14.5 上传到巡瞳 AI 平台

不想自己部署服务，可以把模型传到巡瞳 AI 平台，在平台上接摄像头、配告警（目前支持目标检测模型）：

1. 先在**设置**里配好巡瞳 AI（见 2.3）。
2. 在**部署 → 导出模型**最下面的「上传到巡瞳 AI 平台」，改一下**模型名**，点**上传**。还没导出 ONNX 的会先自动导出。
3. 上传后平台要校验几秒到一分钟，显示「平台正在校验」，校验通过后变成「校验通过」（失败会显示原因）。评估页算出的推荐阈值会一起传上去，作为平台上的默认阈值。
4. 点**打开控制台**，到「自定义模型」里点**启用**，就能接摄像头、配告警了。
5. 下面的「平台上的自定义模型」列出已上传的模型、校验状态和是否启用。没开通托管的账号只能放 1 个模型，要传新版本时先**删除**旧的。
6. 平台上产生的告警图片可以再拉回来标注（见 4.7）。

## 16. 巡瞳 AI 使用指南

巡瞳 AI（[xuntongai.com](https://xuntongai.com)）是一个 AI 识别平台：有现成的专用识别模型（垃圾分类、安全帽、烟火等）和大模型识别，还能托管你自己的模型、接摄像头、推送告警。Wulabel 和它打通后，**标注、训练、上线、现场回流**可以连成一个闭环。前面各章分散讲过用法，这一章集中讲清楚。

Wulabel 里用到巡瞳 AI 的地方：

| 在哪 | 做什么 | 见 |
|---|---|---|
| 设置 → 巡瞳 AI | 登录账号、看额度 | 16.1、16.2 |
| 标注页 → AI 辅助 → 巡瞳 AI | 用专用模型 / 大模型 / 按项目类别自动标注 | 16.3–16.5 |
| 标注页 → AI 辅助 → 识别规则 | 写识别说明、和 AI 聊怎么识别、同步到平台 | 16.5 |
| 部署 → 导出模型 → 上传到巡瞳 AI 平台 | 把训练好的模型放到平台上用 | 16.6 |
| 数据 → 更多导入 → 从巡瞳 AI 拉取告警图片 | 现场的误报、漏报拉回来再标注 | 16.7 |
| 协作 → 在线 · 巡瞳官方中转 | 外网成员连进来一起标 | 16.8 |

### 16.1 登录账号

1. 打开**设置**，在「巡瞳 AI」一栏点**登录巡瞳 AI 账号**。
2. 浏览器会打开巡瞳 AI 的网页：
   - 没登录就先登录（和平时登录巡瞳一样，验证码、短信都可以）；
   - 核对网页上的确认码和 Wulabel 弹窗里的一样，点**允许**。
3. 回到 Wulabel，几秒后显示**已登录**、账号名和套餐、剩余额度，以及能用的识别方式。

说明：

- 不用去控制台创建、复制 API Key：登录时平台会给这台电脑发一个专用 Key，名字是「Wulabel · 电脑名」，在巡瞳控制台的「API Key」页能看到，也能停用。
- 同一台电脑重新登录，会自动换掉旧 Key。个人账号最多 2 个 Key，满了网页上「允许」点不了，到控制台停用一个不用的 Key 再试。
- 浏览器没自动打开：点弹窗里的**重新打开**，或者复制地址自己打开。登录码 10 分钟有效。
- **退出登录**：本机的 Key 删除，登录时发的 Key 在平台上停用。
- 已经有 API Key、或者巡瞳是私有化部署的：点**高级：手动填 API Key、私有化部署的平台地址**。

### 16.2 额度和费用

- 设置页显示每种额度剩多少、什么时候到期：大模型识别、专用模型识别、自带模型识别、加油包等，以你的套餐为准。
- 怎么计：识别一张图算 1 张。批量预标注前会提示总张数；和 AI 聊识别规则每轮算 1 张大模型额度。
- 只花你自己账号的额度；协作成员用 AI 聊天时，用的是发起人的额度（发起人可以在协作页关掉「成员可以用 AI 辅助」）。
- 额度用完时会提示「额度不足」，批量预标注会停下，已经标好的保留。

### 16.3 四种识别方式怎么选

在标注页右侧「AI 辅助」选**巡瞳 AI**，「选择识别模型」下拉里有：

| 识别方式 | 适合 | 速度 | 额度 |
|---|---|---|---|
| 专用模型（如垃圾分类、安全帽） | 项目的类别和平台现成模型对口 | **最快**，批量时 8 张一批、两批同时发 | 专用模型识别 |
| 你上传并启用的自带模型 | 自己训练过、传到平台上的模型 | 同上 | 自带模型识别 |
| 按项目类别识别（推荐） | 平台没有对口的模型；只想找项目里这几类 | 一张一张，慢一些 | 大模型识别 |
| 大模型通用识别 | 按安全隐患大类（消防、电气、环境卫生等）找 | 一张一张 | 大模型识别 |

选法很简单：**有对口的专用模型就用专用模型**（又快又准）；没有就用**按项目类别识别**，把每个类别的识别说明写清楚（16.5）。

### 16.4 用专用模型批量自动标注

以垃圾分类为例：

1. 新建检测项目，导入图片。类别可以先不建：模型识别出的类别名（如「可回收物」）项目里没有时会自动新建。
2. 打开标注页，右侧「AI 辅助」选**巡瞳 AI**，模型选**垃圾分类**。
3. 调**置信度**：先用默认值，框太多就调高，漏得多就调低。
4. 先按 `P` 标当前这张看看效果，满意了再点**批量预标注**。会对所有「未标注」且还没有标注的图逐批识别，进度条显示进度。
5. 识别出的框是虚线（来源「巡瞳」）。逐张检查：错的删掉、偏的拖正、漏的补上，按 `Enter` 通过。
6. 想更快：标几百张后，用这些数据训练自己的模型（第 10 章），以后在本机预标注，不花额度。

批量时遇到「调用太频繁」会自动放慢重试，不会重复扣额度；额度不足、模型没开通这类错误会停下，告诉你已经标了几张。

### 16.5 按项目类别识别和识别规则

平台没有对口的模型时，用「按项目类别识别」：平台只找你项目里的类别，类别名原样对上，**清单外的东西一律不报**。效果好不好，关键看你把规则说清楚没有。

**写识别说明：**

1. 在类别旁的编辑按钮里，填**识别说明**：这个类别具体指什么、什么算 / 不算。比如：
   - 未戴安全帽：头上没有安全帽的人；戴了帽子但没系带也算；只框头和上半身。
   - 电动车：两轮电动车、电瓶车；自行车、摩托车不算。
2. 或者在「AI 辅助」标题旁点**识别规则**，在**当前规则**里集中改**整体规则**（对所有类别都适用，比如「只看画面下半部分的通道，忽略海报和屏幕里的内容」）和每个类别的说明，点**保存规则**。

**和 AI 聊：**不知道怎么写规则，就在**识别规则 → 和 AI 聊**里用大白话说：

- 「戴了帽子但没系带的也算未戴安全帽」
- 「反光衣不算安全帽」
- 「这张图左边那个人为什么没认出来？」

默认会附上当前这张图，AI 回答后会按新规则在这张图上试识别。AI 建议改规则时会列出具体内容，点**采用这些规则**才保存；试识别有结果时，点**把试识别的框加到这张图**直接用。

**同步到巡瞳平台（可选）：**在「当前规则」最下面点**同步到巡瞳平台**，规则会存到平台上。默认不启用，不影响平台现在的识别。

想让巡瞳平台自己的识别（抓拍、告警推送）也只报你项目里的类别，就打开**平台识别也用这套规则**。注意：打开后整个巡瞳账号的识别都按这套规则来，适用场景可以在巡瞳控制台的「识别规则」页调。

绑定后，每次保存或采用规则都会自动同步内容，但不会改你在控制台设的启停和场景。不想同步了就点**解除绑定**，平台上的规则不会删。

**限制：**最多 30 个类别、类别名不超过 30 个字；整体规则最多 1000 字，每个类别的识别说明最多 500 字；每个巡瞳账号最多 20 套规则。

### 16.6 把训练好的模型传到巡瞳

1. 在 Wulabel 里训练一个**目标检测**模型（巡瞳目前只收检测模型）。
2. 到**部署 → 导出模型**，最下面「上传到巡瞳 AI 平台」改个模型名，点**上传**。还没导出 ONNX 的会先自动导出；评估页的推荐阈值会一起传上去。
3. 平台校验几秒到一分钟：显示「校验中」→「校验通过」（或「校验失败」和原因）。
4. 点**打开控制台**，到「自定义模型」里点**启用**。启用后就能在平台上接摄像头、配告警，标注页的模型列表里也能选到它。
5. 下面「平台上的自定义模型」列出传过的模型、校验状态、是否启用。没开通托管的账号只能放 1 个模型，传新版本前先**删除**旧的。模型文件最大 200MB。

### 16.7 拉回现场告警图片，持续改进

模型上线后，现场的告警截图里有误报、漏报，正是最值得补的数据：

1. **数据 → 更多导入 → 从巡瞳 AI 拉取告警图片**。
2. 选时间范围（最近 1 / 3 / 7 天）、哪个模型的告警、最多几张。默认勾选**平台识别出的框作为预标注**。
3. 拉回的图在项目的 `images/xuntong_时间/` 文件夹，框是虚线（来源「巡瞳」）。
4. 逐张改：误报的框删掉（画面里本来没有目标的图直接**通过**，作为负样本），漏的补上。
5. 重新训练、评估，再上传新版本，替换平台上的旧模型。

注意：平台的告警图片保留 7 天，记得定期拉；只有配置了推送通道的账号才会产生告警记录。

这就是闭环：**标注 → 训练 → 上传巡瞳 → 现场告警 → 拉回改错 → 再训练**，模型越用越准。

### 16.8 协作里的巡瞳 AI

- **官方中转**：协作页共享方式选**在线 · 巡瞳官方中转**，外网成员通过巡瞳的服务器连进来，不用自己的服务器。需要先登录巡瞳账号。每个账号最多同时开 3 个共享；图片和标注经过巡瞳服务器转发、不保存。数据敏感的项目用局域网或自建中转。
- **成员能用什么**：成员不能直接用巡瞳 AI 预标注（会花你的额度）；开了「成员可以用 AI 辅助」时，成员可以打开识别规则和 AI 聊（用你的额度）。能不能改规则跟着「成员可以新增、修改类别」开关走。

### 16.9 常见问题

- **点登录后浏览器没反应**：点弹窗里的**重新打开**，或者复制地址到浏览器里打开。公司电脑禁止自动打开浏览器时也这么办。
- **网页上「允许」点不了**：账号的 Key 数量满了，到巡瞳控制台「API Key」页停用一个不用的。
- **显示「连接失败」**：
  - 看提示里的原因；
  - 手动填的 Key 检查是否复制完整（以 `sk-live-` 开头）、在控制台是否启用、有没有设 IP 白名单（登录发的 Key 没有白名单）；
  - 也可以退出后重新登录。
- **提示「额度不足或调用太频繁」**：在设置页看剩余额度；额度用完要到巡瞳续费或买加油包。批量标注本身已经控制了速度。
- **模型列表里没有某个专用模型**：说明账号没开通，到巡瞳 AI 开通对应套餐。
- **识别出的类别名和项目里的不一样**：专用模型按它自己的类别名，项目里没有的会自动新建。想统一名字，用「按项目类别识别」，或者识别后在类别编辑里把名字改掉。
- **巡瞳私有化部署**：在设置的「高级」里填你们自己的平台地址和 API Key。

| 按键 | 作用 |
|---|---|
| R | 画框 / 画轮廓 / 画目标框 |
| V | 选择、调整 |
| S | SAM 智能选取 |
